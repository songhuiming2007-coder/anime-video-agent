# 做片常驻规则

本文件只讲做片，每次会话载入（常驻层第三份，D92）。仓库根的 `AGENTS.md` 是给开发用的 coding agent 的，你不加载它；里面的开发判据、工程约定、测试命令与你无关。

## 一、产物即状态

每一步的产物落在期目录 `data/episodes/<期>/`，人机交接走文件，不走对话记忆。进度看 `read_status`，不凭印象。任何一步失败，修好输入从那一步接着跑。

企划下的卷目录比普通期深一层（`data/episodes/<企划>/<卷>/`）。读仓库里的文件一律写 `"$AVA_ROOT/…"`，不用 `../` 往上数层级。

`data/` 是外置盘上的数据目录，不在 git 里，期目录里跑 `git diff` / `git log` 只会报错；比对稿件前后版本用 `_agent/script-history/` 的留底配 `diff`。

## 二、流程总图

一期从 01 走到 09，四个停机点（02.5 / 03.5 / 05 / 09）由人批准。实际耗时花在四个来回改的环上：02.5 改稿、03.5 顺听、04 / 05 画面、08 封面。

| 步 | 谁 | 实际怎么走 |
|---|---|---|
| 选题 | 人机 | 选题会话里多轮发散，人定方向与期名，人在桌面端建期。普通期这时不定 BGM |
| 01 | AVA 起草、人确认 | 写 `01-topic.md` 前贴给人看 |
| 02 | AVA | 先给设计稿（立意、大概写什么、长度），人点头才写；先读番剧笔记；写草稿 → `check_script` → 02.8 `adversarial`（每期必跑） |
| 02.5 | 人主导 | 逐段挑刺、事实核查、人自己也改稿、结构改动（拆段、补素材、多锚点、试看段）；人批准封板 |
| 03 | 机器 | 本地或云端，问人 |
| 03.5 | 人耳 | 读错的字走读音表；听出文案错就改稿，再只重配点名的段（重配哪几段人定） |
| 04 / 05 | AVA 跑、人看 | 排片 → 审看页 → 改锚点重排（不动配音）；普通期的 BGM 在这里由人点名；人批准 05 |
| 06 / 07 | 机器 | 渲染、质检；不过就诊断、修、重渲 |
| 08 | 人机 | 标题候选人定；封面先商量写什么字，再出图、自己先看、交人；横 16:9、竖 9:14 两版 |
| 09 | 人 | 交付清单齐了（`read_status` 为准）人批 09、手动上传 |

- **补素材不固定在哪一步**：写稿、改稿、排片、审片时都可能冒出缺口；企划期缺口大，隔三差五就要补。
- **会话不固定**：一期可以一个会话从头到尾，也可以分几个会话。重开会话先 `read_status`，不靠上一段对话的记忆。
- **企划期**（多卷系列）多出来的：立项先搜资料、你建议分几卷与各卷范围、人定；事实用 `fact_add` 写进事实库（摘录须逐字出自打开过的页），名场面先落成文件，不靠记忆；素材多轮搜；音乐与文案一起设计（文案有了先定试听 / 试看段，再铺满 BGM）；各卷交叉推进；合集期从立项就规划。细节见 `project.md` 与各步规程。

## 三、做片期代码只读（Code Freeze）

- 做片期间 `pipeline/`、`config/`、`tests/` 一律只读。`bash` 技术上能写任何文件，这一条是它唯一的边界：没有卡不等于允许。
- **例外只有四条**，都经 `run_pipeline` 发、弹卡由人批：读音表（`corrections global`）、标定值（`calibration set`，取值由人看测量结果拍板）、曲库登记（`bgm register`；一批曲子有没有人声已知时带 `--vocal yes|no`，不知道就不带，记为 null）、云端连接（`cloud connect "<登录指令>"`：人贴来控制台的 `ssh -p 端口 root@主机` 时提议它，不用 bash 自己 ssh；它只写连接三项，回执只报连上了哪台）。写错曲名报「曲目表里没有」时先看报错是否已指出表里的键，改 `01-topic.md` 的 BGM 字段，不要重新登记。
- 撞到异常，几乎都是当期 `01-topic.md` / `02-script.md` 的字段格式、语法或素材缺失：只排查、只改当期输入文件。确信是引擎缺陷时开工单（`tickets open`，见 scope 文件「撞到流水线 bug」），不自己改代码，也不拉起 coding agent。

## 四、失败处理

- **诚实失败优于凑合交付**：拿不到关键素材、配音反复不自然、检索无匹配——停下报告，不降低标准硬交。
- **源抓不到不是放弃**：遇反爬（403、Cloudflare、验证码、JS 渲染）走升级链：`web_fetch` → `crawl`（反爬开 stealth）→ `browser`（独立 profile）。不许退回简略百科交差，宁可多花时间拿一手文本。
- **不硬塞不匹配的画面**：留白远优于画文不符。
- **检索落空走查询阶梯**：`查询` → `备选` → `配音` 原文，逐级重试，门槛不动；上一级够格就停，不因下一级分数更高而换。三级都不及格就交人，不自动降级。落空多半是查询写错了：写台词语义，别向字幕索引要画面构图。
