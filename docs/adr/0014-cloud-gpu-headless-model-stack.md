# ADR-0014: 计算与交互解耦 —— 云端 Headless GPU 承载全栈顶配大模型（TTS / ASR / VLM / Embedding）

- **状态**: Accepted (2026-09-08 架构立项)
- **关联**: ADR-0002 (本地TTS), ADR-0003 (视觉索引与VLM门禁), ADR-0005 (文本相似度≠语义理解), ADR-0006 (Qwen3-TTS), D4 (VLM启动条件), D22 (多模态漏斗检索), D23 (配音顺听摩擦力), D25 (CJK音读泄漏治理), B2 (每期人时预算)

---

## 一、 背景与物理瓶颈（The 16GB Barrier）

本项目在 Apple Silicon（16GB 统一内存轻薄本）上成功完成了从零到两期完整二次元长篇史诗纪录片（《借躯降生》14.5 分钟、《皮套囚徒》12.2 分钟）的工业级全流程交付。然而，随着项目从“跑通轻量验证”跨越到“端到端全模态生产”，16GB 物理内存已经遭遇不可逾越的物理天花板：

1. **统一内存过载与 Swap 换页发烫**：
   - 操作系统日常基础占用 8~10 GB，留给模型的实际物理内存仅 5~6 GB；
   - 单个 1.7B 语音模型权重即占 4.3 GB，叠加矩阵运算 KV Cache 与 Whisper 回读质检，频繁击穿物理内存阈值；
   - 频繁触发 SSD 虚拟内存 Swap 换页（带宽仅数 GB/s，比内存慢一个数量级），导致算力总线拥堵、持续高温降频，生成 12 分钟配音长达 15~20 分钟；
2. **模型参数受限衍生的系统内耗**：
   - **配音多音字地狱（D25）**：因 16G 限制只能选 1.7B，小模型语义容量不足，中日同形汉字在潜空间纠缠，引发大面积音读泄漏（世界→秀界、全部→权部、监督→坚督），被迫维护长达数十条的手工错别字表；
   - **画面通道长期瘫痪（D4/D22）**：受制于算力，早期实验选用的 Chinese-CLIP Base 因域偏移在动漫画面上命中率不足，而真正的 VLM 视觉大模型在本地完全跑不动，导致排片第 05 步依赖人工抽检；
3. **商业云端 API 替代路线已被实证否决（2026-09-08 实测）**：
   - 评测证明，商业云端 API（如 CosyVoice 商业版）为了高并发低成本，采用了极度激进的量化剪枝与降噪滤波，声音平庸面瘫（播音腔）、带明显金属编码伪影，彻底抹杀了文学纪录片所需的呼吸感、贴耳感与声情并茂。商业 API 无法作为质量解决方案。

## 二、 决策：计算与交互解耦架构（Client-Server Headless GPU Architecture）

确立**「本地极致交互客户端 + 云端 Headless GPU 顶配算力节点」**的分离架构：

```
┌─────────────────────────────────────────────────────────┐
│                    Mac 本地（随身交互端）                   │
│  • 01 选题与考据               • 07/08 封面参数板模渲染    │
│  • 02 脚本创作与对抗审查       • 09 发布与物料交付        │
│  • 04 画廊人眼抽检与核验       • 零算力开销、无发热、静音   │
└────────────────────────────┬────────────────────────────┘
                             │ Git / SSH / API
┌────────────────────────────▼────────────────────────────┐
│              云端 Headless GPU 节点（AutoDL / Linux）     │
│             [RTX 4090 (24GB VRAM) / 按量计费]            │
│  • 03 配音：7B Flow Matching + LoRA 专属微调 (秒级直出)  │
│  • 03.5 质检：Whisper Large-v3 无损完整版 / SenseVoice    │
│  • 04 检索：BGE-M3 全功能向量检索 + Qwen2-VL 视觉意象把关│
│  • 出片时按需开机 5-10 分钟，跑完即关机（单期算力 ≤ 0.3 元）│
└─────────────────────────────────────────────────────────┘
```

### 1. 交互与高价值决策保留本地
- 01 选题、02 脚本创作、对抗性审查、07/08 封面与标题制作、09 发布等文学与审美决策，全部保留在 Mac 本地；
- 依托 Mac 优秀的显示色彩、便携性与长续航，完全不承担发热模型计算。

### 2. 重型模型推理整体上移云端 Headless GPU
- 采用国内成熟弹性算力平台（如 AutoDL / 恒源云），以按量计费方式（1.2 ~ 1.8 元/小时）按需使用 RTX 4090（24GB 显存）；
- 研发与日常修改在本地；在进入 03 配音与 04/05 渲染阶段时，开机连接，以 **1008 GB/s 显存带宽与 24GB 纯净显存** 执行大模型批量批处理；
- 产物（音频与切片数据）一键下载回本地后立即关机，单期实际 GPU 开机耗时约 5~10 分钟，**单次出片算力成本 ≤ 0.3 元人民币**。

## 三、 全栈模型顶配换代矩阵（The Full-Scale Model Stack）

摆脱 16GB 显存枷锁后，流水线关键模型全面实施顶配代际跃迁：

| 工序环节 | 模块路径 | 本地 16G 现役妥协模型 | 云端 24G+ 顶配换代模型 | 架构收益与痛点根治 |
|---|---|---|---|---|
| **03 配音合成** | `pipeline/tts.py` | Qwen3-TTS 1.7B Base (mlx) | **Qwen2-Audio-7B / CosyVoice 2.0 7B**<br>+ **F5-TTS (Flow Matching)**<br>+ **专属 LoRA 微调** | ① 7B 脑容量彻底解耦中日同形汉字，多音字错读率清零，终结 D25 错别字地狱；<br>② 流匹配非自回归全局去噪，数学上根除跳字、复读与基频塌陷；<br>③ 15分钟 LoRA 微调将音色还原度拉至 98%+；<br>④ 12 分钟成片配音耗时由 15 分钟压缩至 **20~30 秒**。 |
| **03.5 回读质检** | `pipeline/asr.py` | Whisper Large-v3 Turbo | **Whisper Large-v3 (全量版)**<br>/ **SenseVoice-Large** | ① 消除尾部静音重复幻觉；<br>② 专有名词辨识度大幅提高；<br>③ SenseVoice 速度快 5 倍，支持端到端情感状态检验。 |
| **04 台词检索** | `pipeline/subindex.py` | BAAI/bge-base-zh-v1.5 (1GB) | **`BAAI/bge-m3`** (多语种全功能) | ① 8192 超长上下文支持；<br>② 原生跨语言对齐：稿件搜中文意象直接高置信度召回原番日文对白，召回率逼近 100%。 |
| **04 画面视觉** | `pipeline/vindex.py`<br>`faces.py` | Chinese-CLIP ViT-Base<br>(长期搁置中) | **`Qwen2-VL-7B` (视觉大语言模型)** | **彻底激活沉睡的视觉通道（D4, D22）**：<br>淘汰死板的余弦相似度，由 VLM 直接“看”镜头代表帧，实现复杂画面意象精准理解，排片错配率接近 0，解放 05 人审负担。 |

## 四、 财务与经济学推演（Economic Superiority）

1. **重资产购买 vs 弹性租赁**：
   - 购买二手 64G/128G Mac Studio 或高配塔式工作站，需要一次性沉没支出 **约 10,000 ~ 15,000 元人民币**，且面临高昂的设备折旧、噪音与学生宿舍空间限制；
   - 租用 24G 显存 RTX 4090 仅需 **1.5 元 / 小时**；
   - 10,000 元资本支出可兑换 **超过 6,600 小时** 的纯算力时间；
2. **单期制作边际成本**：
   - 按照每期视频配音、ASR 回读与检索占用 GPU 10 分钟计算，单期算力支出仅为 **0.25 元人民币**；
   - 全年制作 50 期大型纪实视频，总 GPU 租赁成本 **≤ 15 元人民币**（连一顿外卖的零头都不到）；
   - **实现了以最低的现金流杠杆，撬动业界最顶级的工业级模型性能。**

## 五、 实施路线与演进闸门

1. **阶段 1：三部曲收官（当前焦点）**：
   - 严格保护现有本地流水线稳定性，全速完成《EGOIST 编年史》第三期《终局葬礼》，实现三部曲圆满交付，积累完整代表作与音视频工业资产；
2. **阶段 2：容器化与 Headless 封装（工序解耦）**：
   - 在 `pipeline/` 中解耦平台相关代码（如 MLX 专有调用），形成标准的 PyTorch / CUDA 执行模块；
   - 编写自动化同步脚本（一键上传稿件、云端运行、一键拉回音频资产）；
3. **阶段 3：7B 语音大模型与 VLM 视觉排片探针（性能爆发）**：
   - 在云端 4090 节点部署 Qwen2-Audio / F5-TTS 试跑第一组对比实验；
   - 接入 Qwen2-VL 验证画意检索漏斗，闭环解决 B2 与 D22。
