# ADR-0013: 双模态片段协议（纯净画面解说 vs 音画同源试听）

- **状态**: Accepted (2026-09-07)
- **关联**: ADR-0008 (剧情时间码直通), ADR-0010 (跨番与异构SP素材), ADR-0011 (流水线泛化改造), ADR-0012 (SP画廊与视觉阅卷)

---

## 背景与问题

在过去，流水线默认将所有切片画面剥离音频（强制 `-an`），背景音乐与旁白配音完全由 `music.py` 与 `render.py` 单独混叠。这种设计对于常规的动画解说非常安全，有效避免了正片台词与旁白 TTS 串音。

但在制作《EGOIST 传奇企划志》等音乐向深度视听纪录片时，暴露出致命痛点：
1. **音画割裂与穿帮**：当文案强调“这是现场原声、摘下耳返听到万人海啸、现场颤抖告白”时，如果画面使用的是演唱会录像，声音却挂的是 CD 录音室专辑，**台上动作、荧光棒节奏与耳朵里的音乐完全对不上（两张皮）**，观众会产生强烈的虚假感与认知失调；
2. **缺乏音画同源机制**：流水线缺乏一种正交语法，能够声明“这个片段的画面和声音必须来自同一个源视频的同一时间戳”。

---

## 决策：双模态片段协议（Dual-Mode Clip Protocol）

确立片段的两种正交形态：

### 形态 1：纯净画面片段（Mode 1: Video-Only）
- **定位**：服务于普通解说微单元（动漫名场面、写实空镜、D类扫图微动）；
- **音频流处理**：强制剥离音频（`-an`），严禁任何原声泄露；
- **声学环境**：配音 TTS 正常发声，底层 BGM 正常弱音铺底（-18dB 侧链闪避）；
- **语法**：默认形态，写常规 `锚点:` 即可。

### 形态 2：音画同源片段（Mode 2: Audio-Visual Sync / AV-Sync）
- **定位**：服务于原声现场试听、官方纯净 MV 纯享、现场真实告白与独白；
- **音频流处理**：**完整保留源视频的原生音频轨**（不加 `-an`），切自同一视频文件的同一时间戳；
- **声学环境**：
  - **配音 TTS 彻底静音停止**（不与配音混叠）；
  - **底层 BGM 完全静音为 0**（不污染现场原声）；
- **语法格式**：在 `02-script.md` 的 `## 音乐段 Mx` 块中声明：
  ```markdown
  ## 音乐段 M5 · 摘下耳返与现场海啸

  源片原声: `EGOIST SP04` 00:21.60-00:41.60
  状态: 前景试听，旁白停止
  音画同源: 是
  过渡: 淡出
  画面: 同源
  ```
- **核心收益**：**台上的 3D 动作与台下的荧光棒摆动，与耳朵里的现场重低音和欢呼声在同一毫秒震动，音画物理绝对同步，误差为 0。**

### 补记（2026-09-13）：让路的边界只到槽位为止

形态 2 的「底层 BGM 完全静音」只覆盖槽位自己占的成片区间，**不是 BGM 的终点**：

- **槽内**：BGM 静音、旁白停，源片原声独占；
- **槽后**：同一首床从槽前的位置接续——曲内位置在槽内**冻结**，听众听到的是一首不被打断的歌，而不是静掉 19 秒；
- **同源槽不是铺底边界**：`_bed_boundary` 找的是下一个**非同源**音乐段，铺底块（`状态: 背景铺底`）跨槽同理；
- **槽位不许落在自然收尾区间内**：收尾段是一整段连续音乐（同曲第二段 natural 的曲内终点会被改写成曲目全长），中途切不出静音——槽落进去等于现场原声被音乐床压着播，`build_timeline` 当场 FAIL，不静默。

缺口实录：旧实现把同源槽当成「下一个音乐段」的边界，第二期【皮套囚徒】把 M7 插进段落 37-38 之后，段落 38-43 整整 94 秒无床（同期片头三处空窗刚修好）。

### 补记（2026-09-13）：自然收尾的画面继承与 `收尾画面:` 逃生舱

段落体里写 `音乐: 「X」 继续播放至完整版结束` 就产生 natural 事件——它播掉该曲剩余的全部时长（**长度由音乐决定，不由画面决定**），成片末尾因此常有一段 1–3 分钟无旁白的纯音乐段。它的画面按下面两条决定：

- **默认继承**：取**同一曲目最后一个前景块**的 `画面:` 源，起点顺延该块时长（`render.py` → `_still_frames`）。所以 M6 的源决定整段收尾画面。**换收尾画面不改时长、不改配音哈希、不碰 04-clips**——它只在渲染期生效。
- **显式覆盖**：段落体里写 `收尾画面: [番名] SxxEyy mm:ss` 就地指定长源（跨番前缀的解析与校验同 `画面:` 行，`_source_path`）。**起始时刻 + 收尾时长必须落在源片片长内**，否则被切前守卫当场拦下——收尾段没有办法在中间再切一个镜头，只能是一个连续切片。

实测（2026-09-13）：一期收尾继承 `罪恶王冠 S01E22 18:16.20`（M6 块 10s）→ 从 18:26.20 连播 208.65s；三期改走 `收尾画面: 罪恶王冠 S01E22 19:54.50` 连播 183.81s，落在该集最后一帧前 0.07s。**同一部番的收尾段落会因此和往期的长收尾段在源片区间上重叠**（本例 72s），判断这段重叠能不能接受是人审的活，机器不拦。

### 补记（2026-09-13）：音乐段画面的短素材放慢（`MAX_SLOW`）

音乐段的 `画面:` 允许指向**比槽位短的素材**，渲染时把「声明的起点 → 源片末尾」这一段按比例放慢铺满（`render.cut(slow=)`，`take = want / slow`，`setpts=PTS*slow`）。上限定在 `MAX_SLOW = 8.0`，越限当场 FAIL 并给出两个杠杆（起点往前挪 / 换长源）——**不静默出一个卡帧的伪静止画面**，因为 2026-08-16 用户拍过「试听段不允许静止画面」，而放慢到 8× 以上观感上已经与静止无异。

**这是踩出来的。** 三期 M1/M2/M3 按物证表 HERO-02/03/04 把画面指向 6s 官方封面微动扫图（SP15/SP16/SP17），槽位却是 17/32/11s——一期二期每处音乐段画面都指向 ≥72s 长素材，三期是唯一一处指向 6s 的。旧实现直接在 `cut` 的守卫 1 报「截取越界」，整期渲不出来；而 `check_script` **只校验 `锚点:` 行、从不看音乐段的 `画面:` 行**，所以这个缺陷躲过了 02.5 与 05 两道人工关，直到 06 渲染才炸。实测放慢系数 5.66×（17.0s）/ 6.39×（32.0s）/ 2.20×（11.0s），三处都在上限内。

> 待办：`check_script` 该补一条「音乐段 `画面:` 的起点+槽位不超源片片长（或超了但放慢系数 ≤ MAX_SLOW）」——本次没加，因为判据要跨到渲染常量，先记着。

---

## 状态与影响

- **对旧期数影响**：零影响。没有声明 `音画同源: 是` 的普通期数继续走原有的 `-an` 画面 + CD BGM 流程。
- **对新期数影响**：
  - 第二期【皮套囚徒】微单元 32 摘下耳返现场万人海啸，采用形态 2；
  - 第三期【终局葬礼】微单元 26 现场告白原声与微单元 28 黑暗读信清唱，采用形态 2；
  - 彻底终结“画面是现场、声音放 CD”的劣质拼凑。
