# ADR-0015：VLM 意象文本化 + 文-文检索 —— 画面语义通道的复活方案

日期：2026-09-10
状态：已采纳（决策层面）。**代码生效闸门：M2 验收**（见末节），此前 `clips.py` 的 `场景` 封印维持原状——本文是「决定这么建」，不是「已经能用」。
前置：ADR-0003（视觉索引分层与第 2 层之死）、ADR-0005（相似度≠语义理解）、ADR-0014（端云解耦）

## 背景

**第 2 层（画面语义）的死因不是命中率，是门槛立不住。** ADR-0003 待实测第 4 条记了完整证据：
CLIP 图文余弦没有绝对含义——噪声地板随反例数量无上界爬升（6 条反例地板 0.4069，加到 20 条
升到 0.4164）、z 分下反例「中世纪骑士的盔甲」(z=5.17) 高过 8/10 条正例、原生 softmax 下
反例「太空中的宇宙飞船」(P=0.896) 高过真命中「一个人的背影」(P=0.034)。三种门槛定法全败，
而「留白远优于画文不符」是铁律，于是第 2 层按预案不建，`场景` 字段当场报错成为终态。

**v1 两期《EGOIST 编年史》的试看反馈把这个旧伤变成了主矛盾**（2026-09-08 施工图第六章）：
纪录片讲客观史实与命运张力，原片没有对应台词，字幕检索覆盖率为 0%；
D2（无台词死角）、D22（多模态漏斗）、B1（排片错配）全部指向同一个缺口——
排片需要一个能理解「画面在演什么」的通道。ADR-0014 解除 16GB 算力墙后，
VLM 逐镜头打标从「数量级上不可行」（ADR-0003 当年估算一季 6 万帧 × 2s = 30+ 小时）
变为「Phase 0 级一次性成本」。

## 决定

1. **废弃 CLIP 图文余弦路线。** 不是弃用模型权重，是否决「图像-文本跨模态余弦当门槛」
   这个机制本身。`vindex.py` 里 CLIP 场景编码路径（`encode_images`/`encode_query`）
   在 captions 索引验收后删除（删除动作按红线先问人）；WD tagger 死代码维持 N1 备忘现状。
2. **画面通道改走「VLM 打标 → 文本嵌入 → 文-文检索」三级**：
   - **Qwen3-VL-8B-Instruct**（云端 24GB+ 卡）对每镜头代表帧生成 ≤30 字结构化中文意象
     描述，必须覆盖时间/空间、人物动作、光影色调、情绪氛围，禁止评价性词汇与剧情推测；
     长镜头（>8s）取 25%/50%/75% 三帧多图输入，其余取 50% 单帧；
   - 逐镜头落盘 `data/library/vindex/<番>_<集键>.captions.json`，meta 自描述
     `model_id` + `revision` + `prompt_version` + `shots_fingerprint`——
     **改 prompt 等于换模型**，版本不一致加载硬失败（ADR-0003 索引自描述标准的延伸）；
   - **bge-m3** 将 captions 嵌入为密集向量（dim=1024）建场景索引；
   - 校验失败（超长/含禁词/空输出）降温重试一次，仍败记 `caption_status: "failed"`
     跳过不定罪（S4），计入对账第七条数字。
3. **门槛标定复用已验证的文-文方法**：`vprobe scene` 用零假设组（本片绝不可能有的
   画面查询）测噪声地板、真实查询测命中带，取中间值按番写入 `config/scenes.json`
   的 `no_match`（R2：按番存，无默认值，缺配置当场报错）。
4. **三通道纪律逐字不动**：路由不是融合、一段只走一个通道、分数只在自己通道内排序
   （S10）、场景通道阶梯两级（`场景`→`备选`）、台词段先挑的显式通道优先级。
5. **检测的不对称平移到 caption 层**：「caption 没提到 X」≠「X 不在场」——
   打标漏细节是常态，因此 `no_match` 硬失败交 05 人审，不许自动塞画面；
   captions 是人可读文本，打标质量本身可被抽查（CLIP 向量不可读，这是本方案的
   隐性审计红利）。
6. **成本闸**：全番打标是 Phase 0 级一次性成本（估算 9~18 元/季，见下「待实测」），
   不进单期 0.3 元预算；预估超 `budget_per_phase0_cny` 时要求显式 `--confirm-cost`。

## 为什么这次门槛立得住

第 2 层死于「图文余弦无绝对含义」。文-文余弦在本项目**有被证明过的标定先例**：
subindex 的 `NO_MATCH = 0.45` 就是拿 10 条零假设查询与 21 条真实查询在同一索引上
量出来的（clips.py 常量注释），两组分布不重叠。画面通道换成文-文检索后，
标定方法论、工具（vprobe）、存储位置（scenes.json）全套复用——
**VLM 在这里不回答「这算不算命中」，只负责把画面翻译成文本**；
「算不算命中」交回给已验证的文-文门槛机制。职责分离是本案的核心。

## 成本估算（待 M1 实测回填）

| 项 | 估算 | 依据 |
|---|---|---|
| 镜头数/季 | ≈ 15,000（41 集 × 370） | ADR-0003 实测 372/集 |
| 单镜头耗时 | ≈ 1~2s（8B FP16，批处理，限长输出） | **待 M1 镜像基准实测** |
| 单季打标 | ≈ 4~8 小时 ≈ 9~18 元 | 按 2.2 元/h 档位估算，实价以卡型为准 |

## 待实测

1. IndexTTS2 之外的本案头号未知数：**Qwen3-VL 在动漫镜头上的 caption 质量**——
   M2 随机抽 30 镜头人看，目标准确 ≥ 27/30，达不到回 prompt 工程，再达不到触发推翻条件①；
2. 长镜头 3 帧是否显著优于单帧（M2 抽 30 个长镜头对照，不显著退回全单帧，YAGNI）；
3. 单镜头打标实测耗时与单季总成本（M1 回填，替换上表估算）；
4. `no_match` 门槛在 captions 索引上的零假设组标定（M2，每番各测一次）。

## 什么情况下推翻本决定

1. **caption 质量救不回**（M2 抽验 < 27/30 且 prompt 迭代两轮仍不达标）→
   退回现状：`场景` 维持封印，氛围/意象段落继续交 05 人审，本文其余部分作废；
2. **文-文门槛也测不出来**（零假设组与真实查询在 captions 索引上分布重叠）→
   与 ADR-0003 第 2 层同判：不建，且这将成为「该索引路线不可行」的强证据，
   画面语义方向整体搁置，不许再换嵌入模型重试第三次；
3. **单季打标成本失控**（实测远超 25 元预算闸且降帧率/降档无效）→
   改为「只打标有字幕时段的镜头」或「按需打标（当期稿件涉及的集）」，修订本文；
4. 推翻只针对画面通道实现路线，不影响三通道纪律与锚点直通（ADR-0008）的任何内容。
