# ADR-0017：v2 配音引擎选型 —— Index 系列出局，Qwen3-TTS 1.7B 胜出

日期：2026-09-11
状态：**部分生效**——Index 系列出局为终审判决；胜者定为 **Qwen3-TTS 1.7B（PyTorch/CUDA）**，
但性质是「唯一可行候选」而非完整 A/B 胜出：CosyVoice 2.0 因部署阻塞未能上桌（见文末回填），
故本 ADR **保持 provisional**，待 CosyVoice 补评后再补终审。
前置：ADR-0006（Qwen3-TTS 选型与商业 API 否决）、ADR-0016（端云分工）、架构方案第三节

## 背景

v2 架构方案 3.1 原定配音选型链：主选 **IndexTTS2**（音色/情感解耦、时长可控、零样本克隆），
备选 CosyVoice 2.0，本地 Qwen3-TTS 1.7B 为诚实降级地板。M2a 单点验证期间，
主选在云端（RTX 6000D）以既有音色资产 seg6 做零样本克隆 probe。

**选型纪律（评审全程有效，任何候选不豁免）**：
- 判据排序：**语速优先、稳定性次之、音色最后**；听整篇不听单句（ADR-0002 先例）；
- **英日歌名死刑案例集一票否决**（ADR-0006 案例：`My Dearest` / `エウテルペ` /
  `The Everlasting Guilty Crown`——EGOIST 三部曲歌名是主食不是佐料，
  不接受「大部分能念对」）；
- **人耳是音色验收的法定仪器**（03.5 停机点的意义所在），音色维度没有也不假装有机器分数。

## 判决：Index 系列出局（终审）

| 成员 | 判决 | 证据 |
|---|---|---|
| IndexTTS-1.5 | 出局（2026-08-15 已判） | ADR-0006：纯中文词表，`My Dearest` 念成 `Femi Dearest Faye`，词表级能力缺失 |
| **IndexTTS-2** | **出局（2026-09-11）** | 云端 probe + 长时间参数微调后人耳验收不通过：①同一参考音 seg6 下**音色有明显杂质/杂音**，微调可达的最佳结果仍不纯净——对照组同参考音的 Qwen3-TTS 干净清晰；②**读速异常偏快**，疑似 Index 系整段时长先验压缩的 v1 同款病灶（tts.py 按句合成的存在理由）；③英日歌名死刑案例复测不通过（「念不了」） |

**出局的性质：声学质量硬伤，不是参数没调够。** 对照实验（同参考音、同文本）证明问题
绑定在模型而非配置。「杂质杂音 + 语速失控 + 歌名失败」三连中任何一条单独成立都够判，
三条齐了不再给第二轮抢救——这正是 M2 单点验证的存在意义：**在烧全季打标的钱之前，
用最低成本把错误选型拦下来。**

## 后续评审程序（进行中）

1. **CosyVoice 2.0 vs Qwen3-TTS 1.7B（PyTorch 版）同表 A/B**：同一 seg6、同一文本集、
   同一判据，盲听打分。注意拆开先例：ADR-0006 否决的是 CosyVoice **商业 API**
   （剪枝量化 + 降噪的服务形态），自托管全参数权重有权重新受审；
2. **Fish Speech S2 候补**：仅当 A/B 胜者音色达标而韵律不达标时获得一个 probe 名额
   （只测情感维度）。前置注意：Fish Audio Research License（研究/非商业免费，商用需授权），
   采用则引擎保持配置可插拔、仓库不打包权重；显存需求 28GB+，24GB 卡退路失效；
3. **若终点是 Qwen3-TTS 1.7B（PyTorch）**：v2 配音收益重新分解为「纯算力墙解除」
   （速度 + 不发烫），音色稳定性继承本地地板；D25 音读泄漏是模型行为，换框架不消失，
   `g2p.py` 照建；`情绪:` 字段的执行能力单独实测，验不出来就在验收报告里如实写
   「韵律维度本期不承诺提升」，不许假装协议已兑现。

## 什么情况下推翻「Index 出局」

仅一条：上游发布修复版本，经**同一 probe 矩阵**（同参考音、同文本、同判据、
死刑案例集）复测全过。**「其余候选全部更差」不构成复活理由**——那种情况下项目落在
Qwen3-TTS 地板上，而那块地板已经证明比 Index 干净。

## 回填（2026-09-11 实测，M2a 单点验证）

### Qwen3-TTS 1.7B（PyTorch/CUDA 版）—— 胜出，但性质是「唯一可行候选」

A/B 未做完整对照（见下），所以这不是「击败所有对手后胜出」，而是
**对手要么已出局（Index）、要么未能上桌（CosyVoice）**。记录仍照实测写：

| 判据 | 实测结果 | 证据 |
|---|---|---|
| **死刑案例集（英日歌名）** | **通过** | `My Dearest` / `エウテルペ` 混读全对（`qwen3_B_multilingual.wav`） |
| **音色**（人耳，法定仪器） | **通过** | 用户原话「音色相当好，很纯净」；对照组 IndexTTS2 同参考音下「浑浊、字听不清」 |
| 与本地 mlx 音色一致性 | 同版权重（`Qwen/Qwen3-TTS-12Hz-1.7B-Base` vs `mlx-community/…-bf16`） | 结构上同源，故 v1 音色资产直接继承 |
| **D25 音读泄漏** | **模型行为，换框架不消失** | raw：`世界` 念成 **sekai**（整词日文音读，比 ADR-0006 记录的「秀界」更重）；`楪祈` 念成「野启」 |
| **g2p 拼音直注有效性** | **验证通过** | 同模型同参考同文本，仅加拼音注入：`世界→SHI4JIE4` 后**读对**（`qwen3_A_raw.wav` vs `qwen3_A_injected.wav`） |

**结论**：ADR-0006 的 D25 治理路线成立，「Qwen3-TTS（音色）+ g2p（读音）」两件事各治一样、
互不替代。本文「若终点是 Qwen3-TTS」一节预测的四点（算力墙解除、音色继承地板、
D25 不消失、g2p 照建）已全部实测确认。

### CosyVoice 2.0 —— **未能评估（部署阻塞，非质量否决）**

- 模型 `iic/CosyVoice2-0.5B` 下载完成（5.3GB）
- 官方仓库 clone 成功，但 `pip install -r requirements.txt` **卡死**：
  pip 缓存 1.1GB 十分钟不变、`ss` 显示零网络连接；换清华源亦未救回
- 用户决定「以后有时间再试」，**故本 ADR 对 CosyVoice 不下任何质量判断**
- 它的先例拆解（ADR-0006 否决的是商业 API 而非自托管权重）**仍然有效**，未来重审时可直接沿用

### Fish Speech S2 —— 未获 probe 名额

按原定触发条件（「胜者音色达标而韵律不达标时」），本次未触发。另注意其
Fish Audio Research License 与 28GB 显存门槛两条前置约束依旧成立。

### 仍待回填

- 胜者的 **cpm 实测（N19）**：本地 v1 为 315，PyTorch 版需重测
- `emotions` / `speed` 字段的最终形态：**实测结论是两个通道都没有情感参数**
  （本地 qwen3_tts 没有；IndexTTS2 有 emo_vector 但已出局），故当前
  `情绪:`/`语速:` 只进 manifest 供 eval 分组统计，不改变声学输出——
  按本文「不许假装协议已兑现」的要求，本期如实记录**韵律维度不承诺提升**
