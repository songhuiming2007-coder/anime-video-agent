# ADR-0012 镜头代表帧画廊与多模态视觉阅卷回填

## 语境（Context）

EGOIST 企划池的 SP01–08（MV/Live/物证）没有字幕，语义检索链路对它们不存在；
资产清单里的时间码最初是脑补占位；让人拉 19 分钟 Live 的进度条记时间码
成本灾难且必漏。需要给「无字幕素材」补一条认知通道：镜头可见、锚点可点、
Agent 可阅卷。

既有存量：`shots.frames()` 已实现一趟解码抽代表帧（`select` 精确帧号 +
张数核对）；`pipeline/sheet.py` 联系表本来就是「给 agent 看图用」的设施
（cover 挑封面走的就是这条路）；锚点语法已支持小数秒与三位分钟。

## 决策（Decision）

1. **代表帧零新代码。** `frames` 子命令直接吃 SP 键（`season=None` 集键天然
   兼容），产物 `data/library/shots/frames/<番>_<集键>/%05d.jpg`，编号与镜头
   序一致（1 起）。CFR 前提由 `frames()` 自带的张数核对兜底；SP 源若混入
   VFR 会在张数对账处当场报，不静默错位。
2. **画廊是零依赖单文件 HTML，图片相对路径引用，不内嵌 base64。**
   `python -m pipeline.shots gallery <番> <集键>` 落
   `data/library/shots/<番>_<集键>_gallery.html`。内嵌 base64 会把几百帧的
   单文件撑到几十 MB、浏览器解析卡顿；相对引用 + `loading="lazy"` 双击即开，
   不需要起 HTTP 服务。暗色四列卡片流，卡片含镜头号、起止与时长；复制按钮走
   `navigator.clipboard`，`file://` 下不可用的浏览器退化 `execCommand` 兜底。
   **复制文本的时间码取镜头 start 精确到小数秒**——吸附正中本镜头，且消除
   「整秒取整落进前一镜头尾帧」的边界歧义（实测 SP04 00:21.56 撞边界
   偏 3ms 落错镜头，已修）。
3. **Agent 阅卷走两级：联系表粗筛 → 单帧细验，时间码只许从镜头表抄。**
   不让 Agent 逐张读几百张单图（上下文必爆、误判无自查）：先读
   `sheet.build` 拼的六列联系表（格标签 `#n MM:SS`）框候选，每个特征给 2–4 个
   候选不许只报一个；候选回到单帧确认；确认后从镜头表 JSON 抄精确
   `start/end` 回填资产清单，每条附证据（镜头号+帧路径）。**机器定位、人拍板**：
   Agent 交候选清单，人在画廊滚 10 秒复核后定稿。从根上消灭「又一轮脑补」。
4. **scdet 对「黑底缓淡出」原理性失明，手动切点补刀。**
   实测 SP05 横滨终场消散段（13:10–13:26）：缓淡出分数全部低于扫描下限 3.0，
   五档阈值（5–20）全部失效、最长镜头恒为 632s——不是阈值问题，是检测原理
   问题。`shots rebuild --also-cut MM:SS,...` 把人眼看准的时刻以无穷大分数
   注入候选切点（照常过 min_shot 归并），写入 `meta.manual_cuts` 留痕，
   后续 rebuild 自动重放；撤销 = 删表重跑 build。手动切点只能来自看过的
   画面，不许脑补。

## 反例（Rejected）

- **base64 内嵌单文件**：DOM 体积爆炸，见决策 2。
- **给画廊引 JS 框架 / 做多选批量导出 / index 导航页**：交互复杂度原生
  HTML 足够；YAGNI，用到再加。
- **给 SP 建字幕索引**：无字幕可索；三级体系分工是「番剧靠字幕检索、
  无字幕素材靠画廊+视觉」。
- **降阈值救消散段**：实测无效（见决策 4），且会把整集切碎。
- **物理拆 SP05 成多文件绕开巨镜头**：污染登记表，破坏性大于收益。

## 后果（Consequences）

- SP01–08 共 442 张代表帧 + 8 个画廊 HTML 已产出；SP05 补刀 4 处
  （12:55/13:10/13:26/18:25），深鞠躬、碎光消散、观众席亮灯三个高潮时刻
  全部可锚。
- `01-assets-video.md` 完成实证回填：B 类三条 MV 物理来源更正
  （SP01=名前のない怪物、SP02=当事者、SP03=咲かせや咲かせ，两条原描述与实物
  不符已更正）；C 类横滨消散落真实锚点；D 类 1/3/4 确认已入库
  （SP06/07/08）；C 类动捕幕后确认**缺素材**，2020 无观众 Live 记述与实物
  不符待澄清。
- 验证：全量测试 786 绿（gallery 4 例 + rebuild 补刀 4 例新增）；六条回填锚点
  逐条过 `_parse_anchor` + 吸附命中冒烟。
