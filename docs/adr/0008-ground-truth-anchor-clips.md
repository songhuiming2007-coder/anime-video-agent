# ADR-0008：排片以番剧笔记 Ground Truth 剧情锚点为一等公民，双塔检索降级为氛围补位

日期：2026-08-27
状态：**已采纳（方向定案），实现未动**——本文只记决策与契约，clips.py / 写稿 skill
的改动属后续施工图，不在本文。
前置：ADR-0005（排片错配诊断）；ADR-0004（集号字段与集级锁定）

## 背景

ADR-0005 已确诊：bge-base-zh 双塔嵌入只证「用词/语气相近」，从未证明「这就是那一刻」。
候选复核（D1）只能把错配判成 `no_match` 交人，**不能凭空生成正确画面**——它降低
错配混进成片的概率，不降低 05 人工负担。

2026-08-26《天气之子·天野阳菜人物志》把这条诊断从「约三成错配」推到了「整类失效」：
18 个段落的口播全部在讲**明确的剧情事件**（麦当劳送汉堡、神宫外苑烟火、暴雪街头逃亡、
警车押解、积雨云顶夺还、坡道重逢），纯文本双塔检索只能匹配到字词相近的台词镜头
（多为说话人正脸或画外音），初排结果大面积「文案在讲剧情、画面在放无关对话」。
人工按番剧笔记的分钟级时间码重排后，18/18 段命中剧情关键分镜。

**核心事实**：这些时间码不是排片阶段才发现的——02 写稿的料单与引用核对早已在
`data/library/notes/<番>.md` 里锁定了分钟级剧情锚点，排片却把这些硬事实扔掉，
退回到不可控的模糊检索。这是设计失误，不是检索模型的能力缺口。

## 决定

1. **写稿侧（02）：每个画面块必须带 `锚点:` 字段**，值为番剧笔记中的剧情时间码
   （形如 `S01E01 17:50`，区间写法 `17:50-18:20`）。没有锚点的段落不得进入 04——
   这把 D2（无台词死角）与 D18（集号/人物字段自觉性缺口）从「靠自觉」升级为机检强制。
   确实无剧情锚点可用的段落（纯氛围/抒情过场）必须显式写 `锚点: 无` 并说明理由，
   不许留空蒙混。
2. **排片侧（04）：锚点时间区间是一等候选**。从镜头表直接取覆盖该区间的镜头，
   起点吸附到最近的镜头切点（防半镜切入）；双塔检索只服务两类情况——
   `锚点: 无` 的氛围段、以及锚点区间时长不足以铺满配音时长时的邻域扩展。
3. **05 人审关卡不变**。「人是唯一关卡」原则不动：锚点通道产出的是机器初稿，
   与检索通道一样必须过 05，不允许自动定稿。

## 理由

1. Ground Truth 直通消除的是**整类**错配（剧情事件段），而候选复核（D1）只在
   候选池里挑错；锚点段甚至对 ADR-0005「唯一没解的死角」（被叙述那一刻没有台词）
   天然免疫——锚点不依赖台词存在。
2. 成本方向是**减**不是加：不新增模型、不新增索引，只把已存在的数据（笔记时间码）
   接进已有的镜头表。双塔检索链保留，只是降级，无拆除成本。
3. 与 ADR-0005 候选方向不冲突：复核探针若继续推进，适用范围收窄到「检索段」
   （无锚点段），量级更小。

## 影响

- `02-script.md` 画面块 schema 增加必填字段 `锚点:` → 需同步 SHOTLIST.md、
  write-script skill、`clips.parse_shots` 与 `check_script` 的校验口径。
- `clips.py` 增加锚点通道：时间码解析（mm:ss→秒）、切点吸附规则、区间跨镜头
  合并策略、与 `集:`/`人物:` 过滤的交互，都属施工图内容，本 ADR 不定细节。
- **本期（2026-08-26）数据不得用作验证样本**：该期 `04-clips.json` 与
  `04-clips.approved.json` 逐字节相同（重排直接改进了机器版），diff 通道已被污染，
  计入 D6 会把「18 段全人工排」统计成「0 differ」。验证必须用一期新番实测。
- D6 量化口径需区分「锚点段」与「检索段」，两类分开统计错配率。
- 对 D1/B1：候选复核探针不取消，但若锚点通道覆盖大部分段落，B1 的阻塞面
  实质缩小，D1 四子题的优先级可重估。

## 推翻条件

- 下期实测锚点段错配率不显著低于检索段（05 人审判定）；或
- 笔记锚点覆盖率过低（大部分段落写不出 `锚点:`，说明笔记精细度撑不起这条链，
  此时回到 ADR-0005 候选复核路线重估）。
