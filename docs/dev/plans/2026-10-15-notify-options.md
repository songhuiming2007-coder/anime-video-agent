附件：[`2026-10-15-notify-options/demo.cjs`](2026-10-15-notify-options/demo.cjs)——**真实原生通知演示**，三个方案各跑一次约 25 秒

## 一、用户场景（UI 规则 1）

- **谁**：人在做 supercell 这类长任务，AVA 一轮要跑几分钟（抓 12 条 MV、配 48 句音、渲染）。
- **窗口**：AVA 窗口 1280×800 或 1440×900，人切到浏览器 / 编辑器 / 别的桌面做别的事，AVA 不在前台、可能被完全遮住。
- **连续做的事**：给 AVA 一个任务 → 切走 → 等它「需要我」或「做完了」时被叫回来 → 处理 → 再切走。
- **每一步要知道**：现在是不是在等我（等人＝不回去就卡住）；还是只是做完了一件事（回不回去都行）；点一下能不能直接到那条会话。
- **今天的状况**：整个 `desktop/src` 没有一处 `Notification`、Dock 角标或弹跳，人只能隔一阵切回来看。

## 二、为什么不是截图

通知横幅、提示音、Dock 弹跳与角标都在 AVA 窗口之外，由 macOS 绘制；截 AVA 窗口看不出三个方案的区别，伪造一张系统横幅又会让人按假的样子选。所以附件给的是**真实发出来的原生通知**：

```bash
cd desktop
npx electron ../docs/dev/plans/2026-10-15-notify-options/demo.cjs A   # 跑完再试 B、C
```

跑起来立刻切到别的窗口。脚本按真实先后发四个时刻：2 s 审批卡（等人）→ 8 s 回合结束 → 13 s 配音作业跑完 → 18 s 停机点 03.5（等人）。2026-10-15 已用方案 C 冒烟跑通（C 不发横幅，没有触发通知权限框）；A / B 第一次跑时 macOS 会问一次是否允许 Electron 发通知。

## 三、三个方案

共同部分（三个方案都一样，不用选）：

- **只在 AVA 窗口不在前台时**通知；人正看着窗口就什么都不发。
- 点横幅 → 窗口提到前台、进入那条会话（复用 `focusWindow` 与 `conv.enter`）。
- Dock 角标 = 窗口不在前台期间攒下的未看事件数，切回窗口即清零。
- 文案：标题说「谁在等什么」，正文是「期 / 卷名 · 一句具体内容」（审批卡给工具与描述；回合结束给回复开头；作业给命令、结果与耗时）。
- 回合失败（`turn_failed`）、作业失败按「等人」处理——失败了不回去就不会继续。

| | 等人（审批卡、停机点、失败） | 做完了（回合正常结束、作业成功） |
|---|---|---|
| **A 等人才弹** | 横幅 + 提示音 + Dock 弹一下 | 只加角标 |
| **B 全都弹** | 横幅 + 提示音 | 静音横幅 |
| **C 不弹横幅** | Dock 一直弹，直到切回来 | 只加角标 |

- **A**：叫你回来的只有「不回来就卡住」的事；做完了的事攒在角标里，下次回来一起看。代价：长任务真跑完时只有角标，你要瞄一眼 Dock 才知道。
- **B**：什么都知道得最快。代价：一轮里「回完了」「配音完了」紧挨着来，几分钟一条，容易被训练成无视横幅，真正等人的那条也一起被无视。
- **C**：最安静，不挡屏幕。代价：Dock 被遮住（全屏应用、Dock 自动隐藏）时完全看不到；没有文字，回去之前不知道是哪一期在等。

**我的倾向：A。** 理由在场景里：D98 的痛点是「不知道它在等我」，A 只在这件事上打扰。但这是交互取舍，按 UI 规则 4 由你选；跑一遍演示再定最准。

## 四、待人定

1. 选 A / B / C（或混合，例如「A，但长作业跑完也弹静音横幅」）。
2. 要不要在设置里给一个总开关（勿扰时全关）——macOS 的专注模式已经能管系统通知，我倾向不做。

## 五、选定后的施工要点（届时写成正式施工图）

- 事件源：`desktop/src/host/sessions.ts` 已收到 `request` / `request_closed` / `stop_points` / `turn_finished` 帧；作业结束从时间线（D71 作业条同源）取。host 在 utilityProcess 里，通知必须由主进程发：host → main 新增一条 `notify` 消息，main 用 `Notification` 与 `app.dock`。
- 去重：同一张卡只通知一次（按 request id）；`request_closed` 后不再补发。
- 机检底线（UI 规则 5）：窗口在前台时不发；点横幅调用 `focusWindow` + 进入对应会话；角标切回清零。人验收（UI 规则 2）：打包版里真实跑一期，切走等通知，记下别扭之处——由人做、人勾。
