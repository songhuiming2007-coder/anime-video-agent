## 三案共同部分（不管选哪个都做）

- 预览区标题做成**文件切换器**（`proto-49A-open`）：按稿件 / 配音 / 排片与成片 / 其他分组；未生成的灰显；生成中的目录带进度（`生成中 4/6`）；可编辑的文件标「✎ 可在此编辑」。侧栏收起时也能选文件（D49 ③④⑤）。
- 编辑器与预览**跟随磁盘**：没有未保存改动时自动重载；有未保存改动时提示、不覆盖（D49 ②）。
- 生成中的目录实时刷新，出一段就能听一段（D49 ⑤）。
- 03.5：**只留一套播放器**（去掉旧队列）；停机卡里的终端打点改为卡内三组 1–5 打点（D50 ②④）。
- 纠错录入走 D51 已施工的 core 路径（读音核对、本段 / 本期 / 全局），界面只渲染结构化字段。

## D49：编辑器放哪

| 方案 | 截图 | 做法 | 得 | 失 |
|---|---|---|---|---|
| A 预览栏内 | `proto-49A`、`proto-49A-open` | 编辑器留在预览栏；窄时「源码 / 渲染 / 要点」三选一，宽时源码与渲染并排 | 布局不跳，对话始终在原位；拖宽预览栏即得并排 | 1280 宽时只能三选一，对照源码与渲染要来回切 |
| B 编辑占中栏 | `proto-49B` | 编辑 `02-script.md` 时编辑器占中栏（源码 \| 渲染并排，要点收成一行），对话挪到右栏 | 编辑面积最大，同时还能和 agent 说话 | 对话位置会跳，进出编辑整屏重排 |
| C 全宽专注 | `proto-49C` | 编辑时盖住中栏与预览栏，三栏都够宽，Esc 回对话 | 三栏同时可读，最接近「坐下来改稿」 | 编辑时看不到对话，要和 agent 来回就得进出 |

**我的建议：A 为默认，标题栏加一个「⤢ 全宽」按钮进 C。** 日常看文件、小改用 A，整篇过稿时进 C；B 的整屏重排代价最大。

## D50：顺听与纠错放哪

| 方案 | 截图 | 做法 | 得 | 失 |
|---|---|---|---|---|
| A 预览区段落表 | `proto-50A` | 预览区一张段落表，每段 ▶ + 全文；在文字上选中错字即弹「这里读错了」小卡（应读、改法、范围、读音核对）；底部常驻「待重配 N 段 · 只重配这 N 段」 | 一眼看全片，标错就地；与 D51 的录入逐字段对应 | 「在对话里顺听」只做到「对话旁边」 |
| B 对话内顺听 | `proto-50B` | agent 配完把段落表作为一条消息发出来，就地播放、就地标错；预览区只放播放器 | 字面满足「在对话里顺听」 | 1280×800 下对话可视区只剩约 250px（停机卡与输入框占掉其余），段多时要在消息里滚 |
| C 逐段顺听 | `proto-50C` | 一次一段大字，上一段 / 重听 / 「这段没问题（Space）」/ 下一段；顶部进度条标出听过、有错的段 | 键盘一路听下去，最省手 | 看不到全片，跳着听不方便 |

**我的建议：A 为默认，C 作为面板里的「逐段模式」开关；对话里 agent 配完的那条消息给一个「▶ 去顺听」按钮，点了打开 A 并从第 1 段播放。** B 在小屏上太挤。
