# 方案：检索降级红旗 + `应为` 批注——把「检索没走顺」翻到 05 人眼前

病根同 ADR-0005：余弦分只证「用词相近」，不证「就是那一刻」。但**当 `查询` 是逐字
台词时，检索几乎必然命中那句台词的精确时间码**（楪祈人物志·一 实测 20/20 段，查询
台词=命中 clip 的 line）。所以任何「检索落点 vs 台词时间码」的比对都是**恒绿信号**
（同 mismatch 报告因 approve=copy 恒 unchanged 的坑），不做。

台词级漏配唯一能钻进来的缝，是**检索没能用上写稿 agent 逐字查询的时候**：台词被
`NON_DIALOGUE_STYLE` 滤掉（如歌词行，见番剧笔记「修了两个真实的管道 bug」第 2 条）、
或台词不够独特被别处顶掉 → 检索降级到 `备选` / `配音原文` / 跨集。这个状态 clips.json
**已有字段记着**（`rung` / `ep_fell_back` / `filter_fell_back`），本方案只是把它翻到人眼前。

## 本方案交付什么（范围先钉死）

**交付一层 review 红旗，不交付任何新检索、不碰视觉索引。** 只读现成字段判「风险段」，
在 04-review.html 标红置顶；外加一个可选 `应为` 批注，仅在降级时作人工兜底的路标。

不做：不新增检索通道；不启用 CLIP `场景` 通道（探针没过、已禁用，ADR-0003）；不看图；
不做门禁（05 仍是人关）。

## 非目标（写死，免得以后误判红旗全绿=画面全对）

**抓不到「画外音」。** rung=1 命中了正确台词、但那一刻说话人不在画面 / 是别人的反应
镜头——台词索引和 rung 字段都瞎，只有抽帧或眼睛能看（楪祈稿段落 4「抽帧 08:55.5
确认她在说，集不在画面里」就是写稿 agent 手动抽帧验的）。这类留 05 人关。
**红旗全绿 ≠ 画面全对（判据 9：跳过不是通过）。**

## 前置条件

- 挂载 data 盘（`data -> /Volumes/Samsung T7`），开工先 `./pipeline/preflight.sh`。
- `uv run pytest` 基线全绿。

## 一、写稿约定（SHOTLIST.md 加一段）

段落可选字段 `应为`：**一句话说清这段画面该是什么，写画面不写台词**（和 `查询` 区分）。

```markdown
## 段落 8
配音：直到那一刻，楪祈用自己的身体挡下了那一击。
画面：
  集: S01E19
  查询: 楪祈用身体挡下那一击的台词      # 逐字台词，正常检索走这个
  应为: 楪祈挡在集面前中弹              # 可选，仅降级时进红旗，做人工兜底的路标
```

判据：**`应为` 只在「这段有明显该对上的画面、但担心逐字查询兜不住」时写**（动作戏、
画外音、被 style 滤掉台词的场景）。泛用段落不写——不写就退回纯降级红旗，不更差。

`应为` **不进检索**，是给人看的路标。想让它真去检索得走视觉索引（CLIP `场景` 通道），
那通道探针没过、已禁用，本方案不碰。

## 二、检查判据（约 8 行，读现成字段，无新依赖）

```
风险 = (rung > 1) 或 ep_fell_back 或 filter_fell_back
若风险 → 段落标红置顶，红旗文案按降级类型：
    rung=2        →「逐字查询没命中，用了备选」
    rung=3        →「查询+备选都没命中，退到配音原文，画面很可能飘」
    ep_fell_back  →「集级没命中，降到季/全空间检索」
    filter_fell_back →「角色过滤为空退回，画面里未必有他」
  且若该段写了 `应为` → 红旗追加一行：「应为：<应为内容>」
```

`filter_fell_back` 顺手纳入：它和降级同类，都是「检索没按预期工作」的显式信号，
review.py 现已单独标它，这里统一归到「风险段」置顶。

## 三、在哪插 / 怎么呈现

- 落 `pipeline/review.py` 的 `build()`：复用现有 `.seg.bad` 红框 + `_ep_label` 降级
  红旗机制，把「风险段」并进 `.seg.bad` 判定并置顶；`应为` 作为红旗内一行文本。
- 打开 review.html：降级段红框靠前，红旗直接说「检索飘了 + 这段本该是 X」，一眼知道
  去找什么，手动兜的两分钟变三十秒。不增加人的动作。

## 四、边界与已知失败模式（先写下，免当 bug）

- **抓不到画外音**（见「非目标」）——最隐蔽的一类，留人眼。
- **红旗 ≠ 错**：降级段不一定配错（备选命中很准的情况有，SKILL 段 15 就是），是提示
  不是门禁。
- **render 洗牌**：本检查在排片层，只保证「这段检索走没走顺」，不管成片位置——与台词
  级漏配同层，不冲突。

## 五、最小验证

- 楪祈两期：预期 flag ≈ 0（全 rung=1），和「这两期没啥可改」自洽。
- 造反例：把某段查询改成索引里被 style 滤掉的歌词行，确认它标红、且写了 `应为` 时红旗
  带出那句——**证明红旗真会亮、`应为` 真会显示，不是恒绿**（本轮已三次栽在恒真信号上：
  mismatch=copy、approved=copy、时间码锚=查询自证；这条验证不能省）。

## 依据

- ADR-0004：集号是剧情知识，检索走集→季→全空间降级链，`ep_fell_back` 由此产生。
- ADR-0005：错配病根是余弦只证用词相近；「会读的复核」需先过探针。本方案不碰复核，
  只暴露检索层已有的降级信号，属该 ADR 未覆盖的低成本旁路。
- ADR-0003：CLIP `场景` 视觉通道按番另测阈值，当前探针未过、禁用。`应为` 因此只做
  路标不做检索。
