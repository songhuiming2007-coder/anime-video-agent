### 1.2 真实用户场景（1280×800 与 1440×900）

- **场景 A（1280×800 小屏笔电常用态：选期 → 开会话 → 看预览）**：
  - 用户打开主窗口（1280×800），左侧栏 `240px` 完整展示「选题 / 企划卡片 / 期目录」和当前期下的会话列表，不再被底部长长的 `01-topic.md`、`03-audio` 等文件树挤占滚动空间。
  - 点击右上或右侧「预览」展开面板（`411px`）：预览区顶部先显示阶段快捷胶囊（`01 选题` / `02 稿件` / `03 配音` / `04 审看` / `05 成片`）+ 完整切换按钮 `[data-testid="preview-switch-btn"]` + 精简封面导入条；点开切换器可展开 `03-audio` / `07-cover` 等子目录直达 `07-cover/c1.png` 或切换「镜头画廊」。
  - 在中栏输入区工具栏（`ModelControls`）直接看到当前模型、带 5 格信号强度条的推理按钮 `[data-testid="effort-btn"]` 与服务商连接徽标 `[data-testid="login-btn"]`；即使会话尚未发过第一条消息（`phase === "none"`），也能立刻切换 `devin/gpt-6-luna` 并点开推理分段滑块选择 `高 (16k)` 或按 `Shift+Tab` 循环，发送首条消息时自动生效。
- **场景 B（1440×900 宽屏多模型工作流：`/login` 接入新服务商 → `/model` 切换 → 调推理强度）**：
  - 用户在输入框输入 `/login` 回车（或点击工具栏「服务商」按钮），弹出模态登录面板 `[data-testid="login-modal"]`：左侧选 `anthropic`（或 `openai-codex` / `deepseek` / `cliproxyapi`），选择浏览器 OAuth PKCE 生成授权链接并粘贴回调码（或直接填 API Key / CPA URL 保存验证），状态立变「✓ 已连接」。
  - 随即输入 `/model` 或点击模型按钮，列表中自动汇总原代理模型与新登录服务商下的模型（带提供商标签与支持的思考档位摘要），一键切换到 `deepseek/deepseek-reasoner` 或 `anthropic/claude-sonnet-4-5`，再通过推理分段条选择 `超高`，首轮对话直接按目标协议（Anthropic Messages `thinking` / Codex Responses `reasoning` / OpenAI `reasoning_effort`）携带对应思考参数发起请求。

## 4. 新常量与关键判据推导

1. **`THINKING_BUDGETS`（Anthropic Messages `budget_tokens`）**：
   - 取值：`minimal=1024, low=2048, medium=8192, high=16384, xhigh=32768, max=64000`。
   - 依据：参考 Anthropic Messages 默认思考预算与 CLIProxyAPI 映射数值，由 AVA 独立内建常量维护（不依赖任何外部 SDK），保证切换到 Anthropic 原生或代理 Claude 模型时思考预算尺度一致。
2. **OAuth 自动续期提前量 `REFRESH_SKEW_MS = 60_000`（60 秒）**：
   - 依据：单轮长上下文预填与 TLS 建连通常在数秒至数十秒完成；提前 60 秒续期可避免请求发出后在网关端恰好跨过过期窗口造成 401 重试。
3. **`config/auth.local.json` 文件权限 `0o600`、Temp+Replace 原子写**：
   - 依据：与 `~/.ssh` 等本地凭据安全常规一致，防止同机非当前用户读取明文 API Key 与 OAuth refresh token。
4. **`PreviewSwitcher` 阶段快捷胶囊集合**：
   - 选取 `["01-topic.md", "02-script.md", "03-audio", "04-review.html", "05-final.mp4"]` 五步主产物：覆盖剧本定题→定稿编辑→配音顺听→审看选片→成片复核完整工作流，同时 5 个紧凑胶囊在 `PREVIEW_MIN = 320px` 宽度下可单行容纳不挤爆高度。
