## 起因

`SKILL.md` §10 交付清单要求每期产出 `02-adversarial.md`：一个**看不到写稿对话**的审查者，把稿件里每条剧情断言追到笔记行与字幕时间码，写稿会话再逐条裁决（采纳 / 驳回 + 理由）并回写。2026-08-20 到 09-06 的 5 期都跑过（《你的名字》那份逐段核对，还抓出「同一句台词全片两处、查询会配错画面」）。

改由 ava 写稿后一次都没跑：ava 没有「开一个零上下文的审查者」的手段，`status.py` 也不拦（纯靠自觉），于是静默断供。董香二期段 21「把董香的台词归给西尾锦、雏实在场写成没人」正是它该抓的。判据 6（规程写了就执行，不执行就删）下它现在处于既不执行也没删的状态。人裁决（2026-10-09）：恢复。

## 设计

### A. 命令

`python -m pipeline.adversarial <期> [--script 02-script.md|02-script.draft.md]`，进 `PIPELINE_MODULES`（会写 `02-adversarial.md`，所以弹卡，不免卡），期目录自动补位。agent 经 `run_pipeline` 调用，不加工具（ADR-0025 不变）。

### B. 审查者只看到什么（零上下文）

一次 LLM 调用、不给工具、温度 0。输入全部**机械预取**，审查者不能自己去查，也就不能「查到一半开始编」：

1. 稿件全文（默认 `02-script.md`，没有则草稿）；
2. 本期各番的番剧笔记（`data/library/notes/<番>.md`，`01-topic.md` 的番表）；
3. 逐段证据：锚点窗口 `[锚点 − 15 s, 锚点 + 配音字数 / 7.2 + 15 s]` 内的字幕单句（复用 `tools._subtitle_lines`）与在场索引（复用 `vindex.who_lines`，含覆盖率与「没列出不等于不在场」那行）；无锚点段只给稿件与笔记。

看不到：写稿对话、记忆、规程、人给过的口头材料。这正是「零上下文」：它只能拿证据核断言。

### C. 输出与自校

审查者返回 JSON：每段若干条 `{断言, 类别（说话人/在场/地点/动作/神态/事件/引文）, 出处（字幕 mm:ss / 在场索引 / 笔记「节标题」/ 无）, 判定（有据 / 与证据矛盾 / 无出处）, 说明}`。

**对审查者自己也防编**：渲染前机械核对每条出处——字幕时间码必须是喂给它的那批字幕里真实存在的一句，「在场索引」必须在喂给它的在场行里能找到，笔记节标题必须在笔记里出现。核不上的出处改判为「审查者引用不存在」并标红，不静默放过。

渲染成 `02-adversarial.md`：第一部分是审查报告（逐段表格 + 「与证据矛盾」「无出处」两张清单置顶）；第二部分「终审裁决」留空表头，由写稿会话逐条填「采纳 / 驳回 + 理由」，采纳的经写稿卡回写 `02-script.md`（D47 既有路径）。

### D. 出网

pipeline 侧**首个**直接调 LLM 的模块。调用一律走 `pipeline.agent.llm.chat_complete`，继承出网断言（受限路径字面量照拦）与 `load_llm_config` 的密钥来源（会话进程注入的环境变量经作业继承，N50 已登记接受）。发出去的只有稿件、笔记与字幕 / 在场证据文本，与写稿会话本来就发的同类；ADR-0020 / Spec 16 加修订注写明「出网调用方 +1：02.8 审查」。

### E. 成本（董香二期实测规模）

稿件 3,121 字、笔记 24,058 字、22 个锚点段的证据约 6,000 字 → 输入约 2.5–3.5 万 token；罪恶王冠 / 伪恋笔记五万多字的期约 5–6.5 万 token。按 gpt-4o 公开价（输入 $2.5 / M、输出 $10 / M）一次约 $0.07–0.20（人民币 0.5–1.5 元），等待一两分钟。实际服务商与单价以 `agent.local.json` 为准（本 spec 未读该文件）。
