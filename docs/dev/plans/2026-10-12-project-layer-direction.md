## 0. 一句话方向

**母目录从「放几份 md 的文件夹」变成 ava 认识的「企划」**：有自己的立项文件、会话、上下文、记忆、跨卷检查和最后一道工序（总装）。凡是属于整个系列而不属于某一卷的东西，不再靠 bash 和人的记忆兜底。

## 2. 需求（按价值排序）

### A. 企划成为一等实体

- 母目录放 `00-project.md`，地位等同企划的 `01-topic.md`：总纲 + **卷表**（卷序、目录名、年份跨度、每卷时长预算）+ 标题 / 封面模板。写入照 `01-topic.md` 的纪律弹卡、覆盖留底。
- 期列表不再展平：卷归在企划下（Python 与 TS 两处同一条规则）。
- 企划本身能开会话：定总纲、跨卷审查、总装。会话挂在母目录上，读域是整个企划（母目录 + 各卷，照旧排除 `03-audio/`、`04-patch/`）。
- 卷会话的读域加上母目录的文本文件（不含兄弟卷——兄弟卷的稿子经 C 的检查进来，不放开随便读）。

验收口径：EGOIST V2 母目录补一份 `00-project.md` 后，sidebar 里三卷归在它下面；企划会话里不用 bash 就能读到三卷的 `02-script.md`。

### B. 上下文多一层「企划」

- 卷会话自动常驻：`00-project.md`（全文或摘要，按长度定）+ 企划记忆。
- **企划记忆**复用 `memory.py` 的整套机制（`apply_op` / 校验 / 来源确认 / 超预算即拒 / 写入弹卡），只是文件落在母目录（如 `00-memory.md`），预算另定。
- 教训分两层存：跨系列通用的（如 TTS 语言滞留、句首不放假名）进全局记忆或 `config/voice.json`；只属于本系列的（封面参数、卷间口径、本系列人名读法的取舍）进企划记忆。EGOIST 踩坑全录把两层混在一份散文里，这是要拆开的原因。

验收口径：新开一卷的会话，第一轮不调任何工具就能说出本企划的分卷边界和至少一条企划记忆。

### C. 跨卷检查（机械缺陷，值得做）

合集是连着看的，单卷各自检查查不出这几类：

1. **镜头跨卷重复**：同一素材、时间重叠的锚点出现在两卷。
2. **配乐跨卷重复**：同一首曲子在两卷都作为前景或片尾出现。
3. **前后卷矛盾 / 讲重复**：对抗审查（02.8）在企划内运行时，把已定稿的前几卷 `02-script.md` 一并作为输入，专查与前卷的日期、成员变动、事件说法冲突，以及同一件事讲了两遍。

1、2 是纯规则，**报警告不拦截**——有意的呼应（比如同一首歌首尾呼应）是合法的，由人判断。3 只改审查的输入，不新增环节。

验收口径：拿 EGOIST V2 三卷的真实数据（只读）跑 1、2，人看命中项是真重复还是有意呼应。

### D. 总装 = 企划的最后一道工序（原 D81）

把 `assemble.sh` 泛化成 `pipeline.assemble`，进 run_pipeline 白名单（弹卡）：

- 部件清单从 `00-project.md` 的卷表读，不另维护一份；
- 截断点从 `pipeline.music.build_timeline` 算，**不写预测值**；
- 过场卡与各卷主体的流参数逐项比对，不一致当场停；
- 拼接后自证：总长 = 部件之和、全片解码零报错；写 `04-assembly.json` 交 qc。

EGOIST 的三条教训必须带进去：截断点写死预测值白留 44 s；过场卡 `yuvj420p` + 立体声与主体（`yuv420p` + 单声道）不同款，`concat -c copy` 不报错但音频静默损坏；末卷片尾完整保留、不裁。

验收口径：用 EGOIST V2 三卷成片重跑一遍，产物与现有典藏版逐项一致（时长差 < 0.1 s、qc 11/11）。

## 3. 不做

- **结构化的史实数据库**（成员、发行、时间线做成数据表）：番剧笔记 + 对抗审查 + C-3 已覆盖，再做是过度工程。
- **跨卷自动写稿 / 自动拆卷**：分卷边界是创作决定，归人。
- **三层以上嵌套**：企划下面就是卷，不再往下。
