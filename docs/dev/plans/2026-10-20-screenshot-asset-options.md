# D122 方案：网页截图素材的正式入库路径

日期：2026-10-20（v0.1，三方案待人选）
关联：issues D122、D123（已改为按放大倍数判）、D99（抓取留档）、D100（候选关卡）、ADR-0021、ADR-0030、ADR-0032

## 一、要解决什么

官方公告、榜单、认证检索页这类「页面本身就是物证」的素材，现在没有正式路径：

1. **AVA 截不了图**：`browser` 只有 `navigate` / `extract_text`。2026-10-19 卷二的 10 张截图（补丁池 SP09–SP18）是 pi 用外部工具截的，从 `/tmp` 直接拷进 `patch_assets/`。
2. **出处与台账全被绕过**：没有候选、没有出处核对、不进 `fetched.json`，只跑过 gate。
3. **截图里有没有要证的东西，没人查**：段 37 那张周刊 ASCII 截图里根本没有配音引语；段 21 的 RIAJ 页写的是「ゴールド（CD）」，和配音「三白金」在画面上打架。两处都是人复核时才发现（见该期 `_agent/overnight-assets-20261020.review.md`）。
4. **整视口带广告**：10 张里 9 张是 1280×633 整视口，带站点导航与广告。原因之一是旧 gate 的「短边 ≥1600」逼人保留整视口；D123 改成按放大倍数判之后，这条压力已经没了。

## 二、三个方案

| | A：`browser` 加 `screenshot` 动作（推荐） | B：`acquire screenshot` 子命令 | C：只补登记口 |
|---|---|---|---|
| 谁截图 | AVA，在已打开的页面上截 | AVA 经 `run_pipeline` 起一个无界面浏览器截 | 仍是人或外部工具 |
| 登录态 | 有：沿用 `browser` 的独立 profile（X、niconico、bilibili 都已登录过，D96） | 没有：profile 被运行中的 `browser` 会话锁着，只能开无登录的新实例 | 不涉及 |
| 裁到证据区域 | 按 `selector`，或按 `text` 找包含这段文字的最小块元素，元素截图 | 同 A | 靠人 |
| 截图里有没有要证的话 | 能查：元素的文本必须包含 `expect_text`，不含就拒（段 37 那类当场挡住） | 同 A | 只能查「页面上有」（对照抓取留档全文），查不了「截图里有」 |
| 出处与台账 | 截图时把页面全文、元素文本写进抓取留档（kind=`screenshot`），台账 `fetched.json` 记 url / 文件 / 留档号；之后走现有 `acquire register` | 同 A | 登记时要求 `--source-url` 在留档里、`--expect-text` 在留档全文里 |
| 工具表 | 不加工具，`browser` 多一个动作（ADR-0032：复用已有工具） | 不加工具，复用 `run_pipeline` | 不加 |
| 代价 | 中：一个动作 + 留档 / 台账接线 + 测试 | 中偏大：要另起浏览器实例，登录站点截不了 | 小，但第 3、4 条只解决一半 |

**推荐 A**：页面已经在 `browser` 里打开（多半是为了核事实打开的），在同一个页面上截最自然，登录态也在。B 唯一的好处是不碰 `browser`，但登录站点截不了，正好是榜单、推特公告这类最常用的来源。C 不给 AVA 截图能力，问题 1 原样留着。

## 三、A 的草案（人选定后再细化成施工图）

```
browser(action="screenshot", url=<已 navigate 的页面>, selector=<CSS> | text=<页面上的一段原文>,
        expect_text=<要在截图里看到的话>, name=<文件名提示>, reason=<为什么截>)
```

- 截图存 `data/library/incoming/screenshots/<名>-<时间>.png`，按设备像素比 2 截（文字清楚，D123 下宽幅裁图照样过）。
- `selector` 与 `text` 二选一；用 `text` 时取包含它的最小块级元素，元素太小（比如只有一行字）就向上取一层，返回实际截到的区域尺寸。
- `expect_text` 用 D99 已实测过的同一套归一化比对（NFKC、去空白、引号括号归一），不过就不落文件、报原因。
- 回执给模型：文件路径、尺寸、留档号、元素文本前 200 字；**不回图片**，要看图另调 `view_image`（D90）。
- 之后照旧：`acquire register --pool <企划>`（D129：企划卷进企划池），gate 按放大倍数判，台账里有留档号可追溯。
- 免卡（与下载素材同级，ADR-0030）；写进 incoming 不算越过任何人工关卡，入池登记才是。

## 四、要人定的

1. 选 A / B / C。
2. `expect_text` 是必填还是可选？必填能挡段 37 那类错，但图表、榜单截图未必有一句话可对（可以填表头或数字）。建议必填，没有可对的文字时填页面上能看到的标题。
3. 截图前要不要求这个 URL 在本会话抓取过（D99 的口径）？建议不要求：截图动作本身会写留档。

## 五、不做

- 不做整页长截图：成片里也是 16:9 一帧，长截图缩进去看不清。
- 不自动登记入池：截图只进 incoming，入池仍是单独一步。
- 不做截图上的标注（框选、高亮）：属于画面设计，另议。
