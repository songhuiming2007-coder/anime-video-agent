# ADR-0007：不支持日语无字幕片源（ASR 兜底仅中文）

日期：2026-08-24
状态：已采纳
前置：无

## 背景

2026-08-22 天气之子实战暴露（issues [D15]，已关闭）：日语无字幕片源触发 ASR 兜底时，
`asr.run()` 默认 `language="zh"`（pipeline/asr.py:51），`ingest.py:117` 未传参 → 强制中文
转录 → whisper 幻觉（油管垃圾 + "pla" 死循环）。更深处：`subindex.py:163` 的 `KANA.search`
丢弃所有含假名的行，语义索引（bge-base-zh-v1.5）与检索链都建立在"ASR 产出纯中文字幕"的
假设上。

复核（2026-08-24）：默认值、调用方、KANA 过滤三处均未变，问题确认存在。7/29 的
`language=ja` A/B 实测只证明显式传参可行，不是修复。

两条路：
1. 支持日语无字幕片源：改语言自动检测 + 检索前置校验 + 假名行处理，动整条中文检索链，成本高；
2. 不支持，走文档声明：明确边界，遇到日语无字幕片源提前拒绝，最小成本。

## 决定：不支持，走文档声明

日语无字幕片源不在流水线支持范围内。ASR 兜底保持默认 `language="zh"`，不做语言检测，
不改 subindex。本决策通过文档声明落地：

- README 2.4 素材表：字幕列标注「**日语无字幕片源不支持**（ASR 兜底仅中文，见 ADR-0007）」
- issues [D15] 已关闭（pending.md 删除）

## 理由

1. 当前业务形态是中文解说视频，片源必然有中文字幕（内封/外挂），日语无字幕是边缘输入；
2. 支持它需要重做检索链的输入契约（假名过滤、中文语义索引、检索前置校验三处），成本远大于收益；
3. 保持默认 `zh` 反而是一种**fail-fast**：无字幕日语片源会转录出明显幻觉内容，排片/检索阶段
   暴露后人工即能识别"此片源不受支持"，不会静默产出错位结果。

## 影响

- 排片或检索阶段遇到幻觉/空检索时，人工应检查片源是否为日语无字幕——是则放弃该片源，
  不是则按既有流程排查（AGENTS.md 判据与失败处理）。
- 若未来出现日语无字幕片源的真实需求，重新评估本 ADR（语言检测 + 假名行处理 + 检索
  前置校验的完整改造）。
