# ADR-0016：数据引力原则 —— 推理上云，片源与渲染留本地

日期：2026-09-10
状态：已采纳
前置：ADR-0014（计算与交互解耦）；修正对象：2026-09-08 v2 重构施工图的云端拓扑

## 背景

ADR-0014 确立了「本地交互端 + 云端 Headless GPU」的解耦架构，但 2026-09-08 施工图的
拓扑图把 **04/05 排片与 ffmpeg 渲染（NVENC）也画在了云端**。这个安排在传输账上
不成立：

| 数据流向 | 量级 | 说明 |
|---|---|---|
| 本地上行：一季片源 | 30~40 GB | 家用宽带上行约 30~50 Mbps，首传 **2~4 小时**，且每换一部番重来一次 |
| 本地上行：每期稿件 + 配置 | KB 级 | `02-script.md` + `config/` |
| 云端下行：每期产物 | < 100 MB | `03-audio/` + manifest + 账簿 |
| 本地渲染成本 | **0 元，5~10 分钟** | 3 分钟 1080p 成片 x264 CPU 编码实测 77s 量级，不占人时 |

云渲染需要片源在云端，而片源上行的成本（时间 + 稳定性风险）远超 NVENC 省下的
几分钟编码时间。**数据在哪，计算就该去哪**——片源重力在本地，渲染就该在本地。

## 决定

1. **云端是纯无头推理节点**，只跑四样：TTS（IndexTTS2）、ASR 回读仲裁
   （SenseVoice-Small / Whisper Large-v3）、VLM 镜头打标（Qwen3-VL）、
   向量建库（bge-m3）。原始片源不出本地（L1 权威副本，见架构方案五.1 存储矩阵）。
2. **排片（clips）与渲染（render/qc）留本地。** 排片的输入是文本索引、镜头表与
   回传的 `manifest.json`——全是本地已有资产 + KB 级回传，嵌入查询在 Mac 上
   秒级完成，无 GPU 需求；渲染是 ffmpeg 确定性管线，本地零边际成本。
   架构方案 `cloud.json` 同步清单 `down` 中的 `04-clips.json` 降级为兼容位
   （仅当将来存在云端排片场景时启用），常态不产生。
3. **VLM 打标所需画面以代表帧形式上行**（JPG，番级一次性约 3GB），
   片源本身永不上行；captions 与向量库（MB 级）下行回本地入库。
4. **成本闸**：单期 GPU 预算 0.3 元按「4090 档位 2.2 元/h × 约 8 分钟」设定；
   实际卡型实价不同（2026-09-10 实测抢到的是 RTX 6000D 48GB）时按实价重算预算线，
   依据写进 `config/cloud.json` 注释（E3：数可以改，依据必须跟着改）。
   Phase 0 级重活（全番打标、超分）单独预算单独批准，不进单期预算。
5. **云端 NVENC 渲染不进 v2 范围**。不是技术上不能，是数据引力下没有理由。

## 已实测的链路事实（2026-09-10，AutoDL 西北B区）

- SSH 跳板握手慢（83~401s 抖动），根因是客户端 GSSAPI 空转，关掉后 0.6s；
  TCP 层 0.016s 正常。**对策：cloud.py 全部远端操作走 ControlMaster 长连接复用**，
  握手税每次会话只付一次；
- 创建实例必须带卡；**无卡模式开机**（0.1 元/h，0.5 核 2GB）入口在实例关机后的
  「更多」菜单——环境搭建与 40GB 模型下载全程无卡模式；
- 无卡模式会释放 GPU，切回有卡时若卡被抢走需等待——选余量充足的卡型（6000D）
  即为对冲此风险；
- 「关机 15 天后释放」：超过 10 天未用则无卡开机 1 分钟再关，重置倒计时。

## 代价

- 每期多两次显式同步动作（push/pull，已由 `ava-cloud` 封装）；
- 本地 Mac 继续承担渲染的 CPU 负载（可接受：5~10 分钟，不挡人）；
- 云端故障时整条 v2 流水线停摆——本地 mlx 的 Qwen3-TTS 通道保留为诚实降级
  （慢但可用），这是有意保留的退路，不是死代码。

## 什么情况下推翻本决定

1. **批量出片常态化**（周产 > 3 期）且本地渲染排队成为人时瓶颈 →
   重新评估云端渲染，单独立 ADR；
2. **上行带宽不再是瓶颈**（升级千兆对称宽带，或素材库迁移到云原生存储）→
   数据引力反转，重议本片源不出本地的边界；
3. 排片将来引入必须 GPU 的环节（如在线 VLM 复核候选镜头）→
   排片位置重议，但渲染留本地不受影响（它与推理无依赖）。
