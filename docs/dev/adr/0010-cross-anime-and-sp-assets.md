# ADR-0010 跨番混剪与非传统素材（MV/Live/SP）摄入与排片规范

## 语境（Context）

在 2026-09-06 之前，anime-video-agent 流水线深度绑定了「一期视频对应一部番」的前提：
- `01-topic.md` 只有单个 `番: <番名>` 字符串；
- 分镜锚点语法为 `SxxEyy 00:00`，默认只在主番 sources 字典内寻址；
- 字幕索引、镜头表、角色在场过滤与曲库均为单一番剧平面结构。

随着「EGOIST 跨次元传奇企划志」（横跨《罪恶王冠》《PSYCHO-PASS》《甲铁城》《Fate》）等跨番混剪体裁立项，单番假设成为了系统天花板。
同时，企划志不可避免地引入大量**非传统番剧素材**：
1. **B 类 · 官方原版 MV 与纯净 OP/ED**（无台标、无字幕，配合音乐段试听）；
2. **C 类 · 3D 全息 Live 演唱会现场与动捕幕后录像**（支撑三次元黑幕暗线）；
3. **D 类 · 现实历史物证**（推特公告、画册大图、reche 出道海报）。

若无规范约束，非番剧素材会导致 `check_script` 判 `集未入库`、`clips` 判 `无字幕索引` 而硬报错崩溃。

---

## 决策（Decision）

### 决策一：跨番混剪引擎标准（已实现，Commit 51133d2）

1. **元数据声明（`01-topic.md`）**：
   支持列表块与逗号声明，列表块优先：
   ```markdown
   番: EGOIST
   素材番剧:
     - 罪恶王冠
     - PSYCHO-PASS
     - 甲铁城的卡巴内利
   ```
   `bgm.anime_of()` 取列表首位为主番；`bgm.animes_of()` 返回全番表。
2. **分镜锚点带番名前缀**：
   - 跨番锚点语法：`锚点: <番名> SxxEyy 00:00`；
   - 未带番名前缀时平滑回退至主番，保持 100% 向后兼容；
   - `check_script` 与 `clips` 按前缀番名路由到对应的 `sources.json` 和 `shots.json`。
3. **企划专属曲库池**：
   `config/bgm.json` 允许注册独立企划/歌手键（如 `"EGOIST": { "tracks": { ... } }`）；
   `bgm.resolve` 跨所有声明番剧池与企划池回查，并统一实测 LUFS 归一化。

---

### 决策二：非传统素材（MV / Live / 历史物证）的「SP 特典集」收编模式

**核心哲学：机制不为每一种特异素材写专属分支，而是将异构素材标准化为流水线已支持的同构数据。**

所有非 TV 季番的视频素材，统一归入企划的 **`SP`（Special 特典）虚拟集号**：

1. **MV 与 Live 演唱会录像**：
   - 存入 `data/library/sources/<企划名>/`；
   - 登记进 `sources/<企划名>.json`，赋予 `SP01`, `SP02`... 编号：
     ```json
     {
       "SP01": { "path": ".../Live_2023_Yokohama.mp4", "duration": 5400.0 },
       "SP02": { "path": ".../Live_2017_Tour.mp4", "duration": 3600.0 },
       "SP03": { "path": ".../MV_Namae_no_Nai_Kaibutsu.mp4", "duration": 320.0 }
     }
     ```
   - 执行 `python -m pipeline.shots --anime <企划名>` 切分硬镜头点（**不需要字幕**）；
   - 文案锚点直接书写：
     ```markdown
     锚点: EGOIST SP01 108:45  # 横滨最终场谢幕
     画面通道
     ```
2. **D 类静态历史物证（公告截图 / 海报 / 概念原画）**：
   - 严禁直接喂裸图给渲染流水线（防止帧率或尺寸破坏视频轨）；
   - **动态微动化处理**：用 ffmpeg 慢推微动（Ken Burns 慢缩放 5 秒）转为 `.mp4` 录像；
   - 同样编号为 `SPxx` 入库，作为标准锚点片段截取。

## 效果与不变量保证（Consequences）

1. **向后兼容性（零漂移）**：
   - 单番期数（如春物、天气之子、你的名字）代码路径与排片产物完全 0 漂移；
   - 现存 702 个全量纯函数测试全绿。
2. **文案心智模型统一**：
   - 文案写作者不需要关心底层是动漫还是演唱会；
   - 想切动漫写 `锚点: 罪恶王冠 S01E01 18:40`；
   - 想切演唱会写 `锚点: EGOIST SP01 14:20`；
   - 全流程走统一的排片、抽检（`04-review.html`）与质检（`06-check.log`）。
