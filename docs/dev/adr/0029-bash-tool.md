# ADR-0029：第 15 个工具 `bash`——不加沙箱的本机 shell（人选方案 B）

日期：2026-10-11
状态：**已通过**（2026-10-11 人裁决：选 B「模型的能力、指令遵循、agentic 一定是越来越好的」；施工授权「放行，继续 D77」）
前置：ADR-0025（第 15 个工具须立 ADR）、ADR-0021（工具表封顶的立法者）、ADR-0026（出网断言只比文件名）、D59（命令 agent 发、人只批卡）

## 背景

伪恋期 09 封面（D77）：人给了桌面上的图，要放进期目录、改名、裁成 16:9 / 9:16 再叠字。ava 做不到，只能叫人进终端敲 `cat … | ava … /import-cover`。每缺一项能力就加一条白名单命令 + 一份 spec，工具表已到 14 的上限。人认为该开放 bash，而不是一直打补丁。

候选三个：A 系统沙箱 shell（`sandbox-exec`：只期目录可写、停机点解封物禁写、断网；2026-10-11 实测可行）；B 不受限制的 bash；C 继续加专用命令。Claude 推荐 A，人选 B。

## 决策

1. 工具表封顶 14 → **15**，`bash` 占第 15 位；第 16 个须再立 ADR（ADR-0025 的口径不变）。
2. `bash` 执行 `/bin/bash -c <command>`，**不限制能做什么**：读写范围、联网、可执行程序都不设限。
3. 复用 `pipeline.jobs` 作业：立项发 `job_created`（作业条 / 时间线照常显示 `bash: …`）、排水、人点停止时整组强杀；不进 `CRITICAL_TOOLS`（可中断），不进 `NEEDS_EPISODE_TOOLS`（选题会话也可用）。context 层：D65 老化占位对 bash 单列文案（同 run_pipeline，执行型不指引重调原命令，改指「用只读命令重新查看」）。
4. **审批**：**单条只读命令免卡，其余每次弹卡**（与 D59「只读免卡、写盘弹卡」一致）。只读判定 `bash_readonly` 宁严勿宽：首词在只读集（`ls pwd cat head tail wc file stat du find ffprobe mdls which echo sips`），`find` 不带 `-delete/-exec/-ok/-fprint…`，`sips` 只带 `-g/--getProperty`，且整条命令不含任何 shell 元字符（重定向、管道、串联、`$` 展开、反引号、换行、转义、括号）；判不准一律弹卡。同一函数也是实现层双保险：未经确认的裸调用只放只读命令。卡上依次是危险标记（宿主静态规则：删除、移动、提权、git 写操作、联网/装依赖、碰 `pipeline/` 或 `config/`、碰停机点解封物；只提示不拦）、用途、目录、命令原文——**危险标记行排在一切模型可控字段之前**，session 取卡面第一处「危险标记:」，用途或命令里夹带同样字样骗不过。
5. 三处**与能力无关**的防护（不算沙箱）：
   - **stdin 接 /dev/null**：协议模式下父进程 stdin 是桌面端协议管道，读 stdin 的命令会吃掉协议帧把会话搞挂；
   - **密钥值不进模型请求**：出网断言只比文件名不看内容（ADR-0026），`cat config/*.local.json`、`env` 会把密钥值原样发给模型服务商。bash 输出进会话前把已知密钥值（`config/*.local.json` 里键名含 key/token/secret/password 的值、会话环境里的密钥变量值，长度 ≥ 8）换成 `[已脱敏]`；子进程环境剥掉这些密钥变量（N50 同一组）；
   - **工作目录 = 当期目录**（无期时为仓库根）。

## 已向人说明、由人接受的后果

- 停机点（02.5 / 05 / 09 的解封物）、Code Freeze（`pipeline/` 源码与 `config/` 只读字段）从「工具做不到」降为「提示词规则」，只靠模型遵守。本项目已有模型无视提示词规则的实例（D44、D54、D69）。
- ava 有 web_search / web_fetch / crawl / browser，网页内容里的注入指令可经 bash 拿到本机用户身份的任意命令执行（钥匙串、`git push`、删除文件）。逐条弹卡是唯一一道人眼关，D44 已见过人一轮批二十多张卡。
- `03-audio/` 等出网受限目录的**内容**可经 bash `cat` 进入模型请求（ADR-0026 的读域硬排除对 bash 不成立）。

## 推翻条件

出现**一次**经 bash 越过停机点（写出 `02-diff.patch` / `04-clips.approved.json` / 定稿封面等解封物）、改动 `pipeline/` 源码或 `config/` 只读字段、或执行了网页内容诱导的命令的实例，即复议方案 A（系统沙箱）。
