# ava 终端交互与作业极简速查 (CHEATSHEET)

本文档是操作员（Operator）使用 `ava` 宿主进行全流程视频制作的日常速查手册。
最后按实际行为校对：2026-09-20（PR7 后）。

---

## 零、一句话心智模型

> **`ava <期>` 进来就是与 AI 制片总监的连续对话**：直接说白话，不用背命令。
> **斜杠命令仍然全在**：`/` 开头的输入零 token、毫秒级返回，键盘流的路径一条没删。
> **有副作用的动作必弹审批卡**：写文件、跑 pipeline 都要你按下 `y`，护栏在执行层不在嘴皮子上。
> **底层命令永远存在**：任何步骤都可以用 `python -m pipeline.X` 独立排查或批处理；两者消费相同的磁盘文件，状态完全等价。

## 一、终端入口命令（怎么进）

在仓库根目录下，最常用的终端入口只有以下几条：

```bash
# 1. 唤起全局期看板（不带参数）：各期阶段、停机卡点与人时；回车默认选 1，输入 idea 进选题会话
ava

# 2. 直达指定期工作台（进入后即与制片总监对话）
ava <期名或期号>
# 示例：
ava 2026-07-30-春物-雪乃适合大老师

# 3. 立项新一期（原子创建期目录并生成 01-topic.md 模板，tty 下直接进入该期对话，重名必拒）
ava new 2026-xx-xx-番名-主题标题

# 4. 无期选题会话（idea scope，写权限为零，用于发散选题、读番剧笔记与比较张力）
ava idea

# 5. 一次性子命令（跑完即退，适合脚本化）
ava <期号> /status    # 打印当期诊断卡后退出
ava <期号> /voice     # 直达顺听配音纠错台
ava <期号> /run tts   # ⚠️ 人手敲的这一行 = 已确认，不弹卡，直接执行
```

> `ava <期> /run <cmd>` 与工作台里敲 `/run <cmd>` **不是同一件事**：前者是你亲手敲的命令行，视为已确认；
> 后者会先弹审批卡片、默认 N。其余一次性子命令（如 `/chat`）不被解析，会落进交互工作台。

## 二、工作台交互（进去了怎么敲）

### 1. 两种输入，一条规则

| 你敲的 | 去哪 | 代价 |
|---|---|---|
| `/` 开头的（斜杠命令） | 快捷键路由，现有代码路径原样 | 零 token、毫秒级 |
| 其它一切（含 `run tts` 这种裸命令） | 交给制片总监，它去调工具 | 费一轮 token（裸命令不做特判） |

进入后是 `ava [<期名>] (<scope>) > ` 提示符，scope 按当前阶段自动推导（`creative` 创意写作 / `pipeline` 流水线制片 / `asset` 资产云端）。

直接说白话的例子：

```text
帮我看下当前排片缺口
跑一下排片看看
根据 01 选题出一版草稿
第 5 段发飘，帮我分析一下标点
```

### 2. 斜杠命令全集（一个都没删）

| 命令 | 适用阶段 | 功能说明 | 典型场景 |
|---|---|---|---|
| `/status` | 全阶段 | 打印 64 宽结构化诊断卡 | 不知道下一步干啥时敲，看【下一步动作】与【推荐命令】 |
| `/board` | 全阶段 | 唤起全局期看板（含各期人时） | 制作中途想查看其他期进度 |
| `/run <cmd>` | pipeline | 安全执行白名单工序命令 | **弹审批卡 → 敲 y 才真跑**，带耗时统计与尾部日志 |
| `/voice` | pipeline | 进入配音顺听纠错台 | 03 配音完成后，戴耳机极简挑错字、改读音、钉种子 |
| `/chat` | creative | 聚焦选题发散（独立子会话） | 01 阶段梳理核心张力、人物弧光与矛盾 |
| `/script` | creative | 聚焦写稿（独立子会话） | 02 阶段自动调阅选题与资料库笔记，产出 `02-script.draft.md` |
| `/asset` | 特殊 | 切入 Phase 0 资产与云端调度模式 | 放行 `faces`, `shots`, `vindex`, `cloud`, `ingest` 命令 |
| `/pipeline` | 特殊 | 退出 asset，切回自动工序模式 | 完成底层资产维护后切回常规制片 |
| `/scout` | pipeline | 生成 pi 侦察派工单 | 缺料/缺笔记/标题候选时生成自包含工单交给 pi 采掘 |
| `/patch` | pipeline | 生成临时补料派工单 | `/scout --type patch` 别名（缺料段派工） |
| `/help` | 全阶段 | 查看命令列表 | 随时查看帮助提示 |
| `/quit` `/exit` | 全阶段 | 退出 ava 交互终端 | 进度 100% 依赖落盘文件，随时安全退出 |

- `/chat` 与 `/script` 各自持独立会话历史，**退出后主会话历史不被污染**（进去前聊到哪，出来还是哪）。
- 不认识的斜杠命令（如 `/statsu`）会零 token 报「未知命令」，不会被送去问模型。

### 3. 审批卡片（有副作用的动作都要过这一关）

```text
┌─ 执行审批 ──────────────────────────────────────────
│ 工具: run_pipeline
│ 命令: /…/.venv/bin/python3 -m pipeline.clips data/episodes/<期>   ← 规范化 argv 原文
│ 性质: 本地只读产物生成 | 预计分钟级
│ 危险标记: [停机点] [05] 当前处于停机点 05 审时间码
└─ 执行? [y/N]:
```

| 危险标记 | 什么时候出现 |
|---|---|
| `[计费] ☁计费` | `cloud up/run/push/pull`（云端实例开机烧钱） |
| `[长任务]` | `render` 渲染（分钟级） |
| `[停机点]` | 命令含 `--approve`（或它的 argparse 缩写，如 `--app`），或停机点未过时推进 `tts`/`clips`/`render` |
| `[跳过人工闸]` | 命令含 `--confirm-patch`（或缩写 `--conf`），补丁段二次确认将被跳过 |
| `[覆盖]` | `write_episode_file` 目标文件已存在 |

**按键纪律**：

- **默认 N**：回车、EOF、任何非 `y` 输入一律不执行——注意只有单个 `y` 算批准，敲 `yes` 不算。
- **只读工具免卡**：`read_artifact` / `read_status` / `search_notes` / `list_episodes` 四个只读工具不弹卡，只回显一行 `[tool] read_artifact 01-topic.md`，让你看见模型在读什么。
- **拒收不弹卡**：`--force`、白名单外、未注册/超 scope 的工具在弹卡**之前**就被拦下，直接 `[REJECT] <具体拒因>` 回喂模型（它分得清「护栏拒的」和「你拒的」）。
- **留痕**：每次按键都追加一行到 `data/episodes/<期>/_agent/approvals.jsonl`（时间、工具、规范化命令、y/n、决策耗时秒数）——这是审批疲劳的唯一读数来源。

### 4. `/run` 的核心纪律与放行表

- **放行模块**：`check_script`, `tts`, `clips`, `review`, `render`, `qc`, `cover`, `bgm`, `status`；
- **参数自动补齐**：敲 `/run clips` 会自动注入当前期的完整路径；敲 `/run tts --redo 3` 也会自动注入当期路径；
- **坚决拒收**：`--force` 与 `--force-all` 会被当场拦截，并指引你使用增量参数 `--redo <段号>` 或 `--apply-patch`。

## 三、配音顺听极简纠错（`/voice` 模式专用）

03 语音合成完成后，在工作台输入 `/voice` 进入顺听台。

### 1. 听音与控制指令

```text
听 5           # 调用系统 QuickTime 单独打开第 5 段音频（seg-05.wav）复听
听             # 从第 1 段开始自动顺序播放全篇音频（按总时长给出预计时间）
停             # 播放中随时输入「停」叫停音频序列
回滚 5         # 第 5 段改坏了，一键恢复为上一版的备份音频
撤回 2         # 删除指定 id 的纠错条目
done          # 顺听录入完毕，退出并询问是否立即执行增量重配（--apply-patch）
/quit         # 退出顺听模式（已落盘的纠错条目依然保留在 corrections.json）
```

> ⚠️ `done` 的重配确认是 **`[Y/n]`——回车即执行**，与审批卡的「默认 N」相反。不想立刻重配就敲 `n`。

### 2. 人话纠错文法（随手敲，自动生成补丁卡片）

- **字词级多音字/错读（拼音注入）**：
  ```text
  5段 假装 念成 jiǎ 改成 jià
  段落 8 重叠 念成 zhòng 改成 chóng
  12段 银行 改成 yín háng
  # 简写：只写段号 + 词 + 目标读音
  5段 假装 jià zhuāng
  # 若该词在全片多处出现且都念错，加「全局」
  全局 5段 乃 念成 réng 改成 nǎi
  ```

- **听感整句异常（钉新种子，换音色感觉）**：
  ```text
  12段 语气发飘 换种子
  3段 语气发闷 换种子
  ```

- **回显确认**：敲完后终端会打印结构化补丁卡片，敲 `y` 即可原子追加落盘到 `03-audio/corrections.json`；
  顺听完敲 `done`，系统会自动调用 `--apply-patch` 进行靶向重配，**仅重新合成受影响的段落**。

## 四、一期成片标准 9 步走查表

| 步骤 | 阶段 | 你在 ava 终端做什么 | 产物 | 🛑 停机卡点规程 |
|---|---|---|---|---|
| **01** | 选题 | `ava new <期名>`，人填 `01-topic.md` | `01-topic.md` | 张力由人脑判定，严禁机器代填 |
| **02** | 写稿 | 敲 `/script` 或直接说「根据选题出草稿」，跑 `/run check_script` | `02-script.draft.md` | 机检全绿方可进入下一阶段（条数随判据迭代，以 `check_script` 实际输出为准，不写死） |
| **02.5** | **改稿** | 人工精修事实，另存为 `02-script.md` 并打 patch | `02-script.md`<br>`02-diff.patch` | **🛑 停机点 1**：必须通读改稿，无 patch 渲染器拒绝启动 |
| **03** | 配音 | 敲 `/run tts` | `03-audio/seg-*.wav` | 首次全量合成；后续一律只补点名段 |
| **03.5** | **顺听** | 敲 `/voice` 顺听抽检，白话纠错，敲 `done` | `03-audio/corrections.json` | **🛑 停机点 2**：抽检开头与最长段，用 `--apply-patch` 重配 |
| **04** | 排片 | 敲 `/run clips` | `04-clips.json`<br>`04-review.html` | 三通道自动贪心占坑；有缺口敲 `/scout`（或 `/patch`）生成工单交由 pi 采掘补料 |
| **05** | **审片** | 浏览器审 `04-review.html`，敲 `/run review --approve` | `04-clips.approved.json` | **🛑 停机点 3**：确认无声画错位后显式 approve 封板。卡片会打 `[停机点]`，**那一眼就是全部防线** |
| **06** | 渲染 | 敲 `/run render` | `05-final.mp4` | 自动执行双重切片校验、字幕折行、BGM 侧链闪避 |
| **07** | 质检 | 敲 `/run qc` | `06-check.log` | 11 项机器硬门禁自动化检验（音画同步、黑帧等），以日志实际输出为准 |
| **08** | 封面 | 敲 `/run cover` | `07-cover/`<br>`07-titles.md` | 自动提取候选池与 5 条标题建议（严禁机器定稿） |
| **09** | **发布** | 人类挑选标题与封面，手动上传平台 | 各平台稿件 | **🛑 停机点 4**：人类拍板发布，归档本期 |

## 五、模型配置速查

优先级：`config/agent.local.json`（本地隔离，不进 Git）> `config/agent.json`（仓库内通用默认）。

```json
{
  "base_url": "http://127.0.0.1:8317/v1",
  "model": "gemini-3.8-flash-high",
  "api_key_env": "CPA_API_KEY"
}
```

- **换模型**：只改 `"model"` 字段（例如切成 `kimi-k2.5`）；
- **环境变量**：在 `~/.zshrc` 里确保 `export CPA_API_KEY="..."`（密钥绝不写进仓库文件）；
- **无模型降级**：未起 CPA 或未配 Key 时，任何自然语言输入都打印 `[降级模式·本地纯指示]` 并给出人工清单，
  **快捷键照常可用**，不抛裸异常；`/chat` `/script` 同样降级退出。

## 六、常见告警与脱困口诀

1. **报 `[REJECT] 禁止在 ava 中使用 --force`**：
   - 永远不要在 ava 中强制全量重配。单段重配用 `/run tts --redo <段号>`；纠错重配用 `/voice` 敲 `done`（走 `--apply-patch`）。
2. **看板出现 `⚠️ approved 已过期，必须重走 05`**：
   - 说明 05 封板后，上游的脚本或配音又发生了改动，时间码已漂移。必须重新在浏览器审查 `04-review.html` 并重新执行 `/run review --approve`。
3. **报 `🛑 [CODE FREEZE WARN] pipeline/ 源码存在未提交改动`**：
   - 制片期间严禁修改 `pipeline/` 源代码。请通过 `git status` 撤销对流水线代码的偶发修改。
4. **报 `data/episodes 不可达`**：
   - 检查 Samsung T7 移动硬盘是否已插紧挂载（路径 `/Volumes/Samsung T7/anime-video-data`）。
5. **长任务（06 渲染）想中途叫停**：
   - 直接按 `Ctrl-C`：宿主会杀掉渲染子进程并退出，不会留一个后台 ffmpeg 继续写 `05-final.mp4`。
     重新渲染前先把半成品删掉，否则两个 ffmpeg 会写同一个输出文件。
6. **卡片弹出来但你不确定要不要按**：
   - 默认就是 N，直接回车最安全；想让它改方案，回一句白话告诉它哪里不对（拒因会回喂模型，它会换个路子再来）。

## 七、跑完一期，该看的三个读数

单测给不了、只有真跑一期才有的东西：

| 读数 | 位置 | 用来判什么 |
|---|---|---|
| 决策耗时分布 + `n` 占比 | `data/episodes/<期>/_agent/approvals.jsonl` 的 `decision_latency_s` | 审批疲劳：决策延迟近似 0（秒按 y）且 `n` 占比≈0 → 卡片没在起作用 |
| `k` 值（人类分钟 ÷ 片长分钟） | `data/episodes/<期>/human_time.json` | 人类预算口径（`k × 片长`），取代已被否证的「每期 ≤10 分钟」 |
| 单期 LLM 账单 | 端点后台 | 成本锚点（粗线：单期 > ¥5 就该重做上下文管理） |
