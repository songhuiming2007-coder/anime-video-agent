# Issues：anime-video-agent 未解决问题记录

用途：集中记录本项目**还没有解决**的问题。已解决的不记在这里——历史归 `docs/adr/` 和 git，
这里只活当下的问题。

## 结构约定

| 文件 | 装什么 |
|---|---|
| `blocked.md` | **阻塞后续**——不解决就卡住流程/质量的关键问题（如排片错配、止损线超限） |
| `pending.md` | **待决策**——有明确决策点、没拍板的事（含触发式挂起） |
| `notes.md` | **低优先级备忘**——已接受/已知妥协/触发式，短期不动 |

按**状态**分文件不按来源分：一条问题的状态会变（备忘 → 待决策 → 阻塞 → 解决），
解决即删。来源位置写在每条内部，靠它回原文档。

## 每条记录的格式

```markdown
### [B1] 问题一句话标题
- 状态：阻塞（每档一条按此填）
- 位置：docs/adr/0005:4-6（能回到原文档的位置）
- 描述：问题是什么，为什么没解决
- 线索：已有的结论 / 证据 / 方向
- 推进：解决它需要做什么，触发条件是什么
```

编号规则：`B`=blocked、`D`=pending（待决策）、`N`=notes（备忘），按文件内顺序编号。
编号稳定不重排，删一条不补号。

## 维护纪律

1. **解决即删**——问题解决后从对应文件删掉条目，不保留"已解决"残骸（历史在 git）。
2. **编号不回填**——删掉 B1 后 B2 不变号，避免每次删条都改一堆引用。
3. **新增来源**：发现新问题就写进对应档，一条一个编号。
4. **状态迁移**：备忘 → 待决策 → 阻塞按实际影响升级，反向降级也允许，改状态只需挪文件。
5. **2026-08-12 建库**：首轮摸底自 ADR/文档/代码/skills 注释与 ADR 候选方向，共 29 条
   （3 阻塞 + 13 待决策 + 13 备忘），来源是探索代理对全仓库的穷举扫描，每条位置可回查。
