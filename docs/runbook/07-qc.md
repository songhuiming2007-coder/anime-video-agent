# Runbook: 07 自动质量门禁（QC）

对成片进行 11 项机器硬指标自动化检验（7 项画面音频 + 4 项字幕）。

## 执行命令
```bash
python -m pipeline.qc data/episodes/<期号>
```

## 产物与位置
- `data/episodes/<期号>/06-check.log`

## 11 项核心质检标准（不达标非零退出）
1. **时长目标**：落在目标带（默认 2–4 分钟或 `01-topic.md` 指定带）；
2. **音画同步**：全局音画对齐误差 < 0.5 秒；
3. **音频响度**：整片积分响度 -16 LUFS，True Peak ≤ -1 dBTP；
4. **异常静音**：无连续 > 2.0 秒无意图静音（自然停顿与音乐结尾除外）；
5. **异常黑场**：无连续 > 0.5 秒非艺术黑帧；
6. **字幕完整度**：无空白字幕卡；
7. **字幕版式**：单卡不多行、不超安全画幅宽、不超高。

## 异常处置
- 任何一项 FAIL 则终端报错退出，禁止流向下游。
- 质检反映的是排片或配音问题，回到 `02`、`03` 或 `04` 修复后重跑。

## 07.2 质检门禁与回读质检参数表

- **质检门禁（渲染后自动，不达标打回，不进人工环节）**：时长落在目标带（默认 2–4 分钟，可被该期 `01-topic.md` 的 `时长目标` 字段覆盖，见「九、内容参数」时长行）；音画误差 < 0.5s；响度 −16±1.5 LUFS、true peak ≤ −1 dBTP；无 >0.5s 黑帧、>2s 静音；字幕无空段、不超宽、每卡一行、不超高。**主观项（节奏、观感）不进门禁**——根在稿子和排片，回 02/05 改，不在成片上补救。
- **配音回读质检**：每段生成后 Whisper 回读，不过换种子降温重生成，三次仍不过整体退出，不留坏音频。比对在**带声调拼音**上做（`tts.syllables()`）——按字形比，量到的是「ASR 认不认识人名」，不是「TTS 念没念对」；同音字（他/她/它）折叠只折读音完全一致的。含英日歌名段 CER 可能虚高（回读听岔假名），歌名区段做豁免，不放松整段阈值（ADR-0006）。**ASR 盲区豁免（2026-08-16 改）**：三个不同种子生成的音频 Whisper 全部严重失真（CER 远超门槛）而时长达标时，判为 ASR 对音色的盲区而非 TTS 念错——跳过样本不定罪（S4），保留音频标 `qc_skip`，成片交人前必须人耳确认。豁免判据就是「3 次全不达标 + 时长达标」，**不再要求回读文本两两相似**（2026-08-16 段落 5.1 实测：失真模式在假名乱码与近音中文间摇摆，内容互不相似而音频念对；旧判据会卡死整期）。跑飞由时长闸拦（漏读/重复改变时长）+ 人耳确认兜底。
