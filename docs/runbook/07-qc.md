# Runbook: 07 自动质量门禁（QC）

对成片进行 10 项机器硬指标自动化检验（6 项画面音频 + 4 项字幕）。成片总时长随内容自然决定，不设门禁。

## 执行
agent 跑 `qc`（期目录自动补上）。底层排查参考：`python -m pipeline.qc data/episodes/<期号>`。

## 产物与位置
- `data/episodes/<期号>/06-check.log`

## 10 项核心质检标准（不达标非零退出）
1. **音画同步**：全局音画对齐误差 < 0.5 秒（同时记录画面实测时长）；
2. **与排片一致**：成片时长与已批准排片 / 总装账本一致（误差 < 0.5 秒）；
3. **积分响度**：整片积分响度 -16.0±1.5 LUFS；
4. **真峰值**：True Peak ≤ -1.0 dBTP；
5. **异常黑场**：无连续 > 0.5 秒非源片自带的纯黑帧（SP 特典素材放宽至 1.5 秒）；
6. **异常静音**：无连续 > 2.0 秒无意图静音（歌尾与合集过场卡除外）；
7. **字幕无空段**：无空白字幕卡；
8. **字幕不超宽**：按 `subtitle_metrics.py` 真实 libass 像素宽校验（1080p 下 ≤ 1680 px）；
9. **字幕每卡一行**：不出现显式折行或超宽自动折行；
10. **字幕不超高**：总行数不超过画幅安全高度上限。

## 异常处置
- 任何一项 FAIL 则非零退出（agent 把失败项原样转给人），禁止流向下游。
- 质检反映的是排片或配音问题，回到 `02`、`03` 或 `04` 修复后重跑。

## 07.2 质检门禁与回读质检参数表

- **质检门禁（渲染后自动，不达标打回，不进人工环节）**：上述 10 项全绿通过（音画误差 < 0.5s、与排片/总装一致 < 0.5s、响度 -16.0±1.5 LUFS、true peak ≤ -1.0 dBTP、无 >0.5s 异常纯黑 [SP ≤ 1.5s]、无 >2.0s 异常静音、字幕无空段/不超宽/每卡一行/不超高）。**成片总时长与主观项（节奏、观感）均不进门禁**——内容问题回 02/05 改，不在成片上补救。
- **配音回读质检**：云端按 `SenseVoiceSmall` 主读 + `Whisper Large-v3` 仲裁级联回读（自动剥除 `<|...|>` 控制标签），本地使用 `mlx-whisper`。每段生成后先查时长带与 **2.0 s 句内连续静音门禁**（D87，不豁免），再查回读 CER（错数 ≥3 且 CER > 20%）；不过就换种子降温重生成，三次仍不过且时长/静音均达标时转 ASR 盲区豁免，**其中含假名或 ≥2 个拉丁专名的句子在首次时长与静音达标时直接按 `asr-blind` 放行**（D167）。比对在**带声调拼音**上做（`tts.syllables()`），同音字折叠只折读音完全一致的，英日歌名区段单独豁免（ADR-0006）。标 `qc_skip` 的盲区段在 03.5 交由人耳确认。
