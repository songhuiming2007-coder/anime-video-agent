# Runbook: 07 自动质量门禁（QC）

对成片进行 11 项机器硬指标自动化检验（7 项画面音频 + 4 项字幕）。

## 执行命令
```bash
python -m pipeline.qc data/episodes/<期号>
```

## 产物与位置
- `data/episodes/<期号>/06-check.log`

## 11 项核心质检标准（不达标非零退出）
1. **时长目标**：落在目标带（默认 2–4 分钟或 `01-topic.md` 指定带）；
2. **音画同步**：全局音画对齐误差 < 0.5 秒；
3. **音频响度**：整片积分响度 -16 LUFS，True Peak ≤ -1 dBTP；
4. **异常静音**：无连续 > 2.0 秒无意图静音（自然停顿与音乐结尾除外）；
5. **异常黑场**：无连续 > 0.5 秒非艺术黑帧；
6. **字幕完整度**：无空白字幕卡；
7. **字幕版式**：单卡不多行、不超安全画幅宽、不超高。

## 异常处置
- 任何一项 FAIL 则终端报错退出，禁止流向下游。
- 质检反映的是排片或配音问题，回到 `02`、`03` 或 `04` 修复后重跑。
