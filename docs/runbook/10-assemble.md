# Runbook: 10 企划总装（多卷 → 合集）

企划（多卷系列）各卷都出完成片后，把它们拼成一期合集。**只在企划会话里跑，每次都弹卡由人批**（D81，人裁决 Q5）。

## 输入物
- 企划目录下的 `00-project.md`：卷表决定部件顺序与每卷片尾（`余韵<整数>秒` 截到「旁白终点 + N 秒」；`完整保留` 与字面 `余韵N秒` 都原样拼接，后者的刀口由 `cuts.json` 的 `tail_at` 在总装前填），`合集:` 指向输出期。
- 每卷：`05-final.mp4`、`08-cover.jpg`（过场卡素材）；`余韵N秒` 或被删减清单点名的卷另需 `02-script.md` 与 `03-audio/manifest.json`（算时间轴）。
- 合集期目录：要先建好且有 `01-topic.md`（qc 读它的 `时长目标`）。可选 `cuts.json`：期级人定删减清单——`volumes` 按卷目录名给 `remove: [[t0,t1),…]`（中段切除，可多段）与 `tail_at`（定点截尾），均以卷成片时间轴计；`seam_fade_s` 配缝口淡出淡入（默认 0.5s）。定点截尾与 `余韵N秒` 取严（小者）。

## 命令
```bash
python -m pipeline.assemble data/episodes/<企划>                # 输出到合集期
python -m pipeline.assemble data/episodes/<企划> --out <目录>   # 输出到别处（目录须已存在、有 01-topic.md）
python -m pipeline.assemble data/episodes/<企划> --replace      # 覆盖已有 05-final.mp4（不留底）
```
企划会话里由 ava 经 `run_pipeline assemble` 发起，卡面列出部件、每卷截断点与输出位置；带 `--replace` 时卡面首行是「⚠ 将覆盖已有 05-final.mp4（不留底）」。卡不开放「本会话都批准」；bash 直接跑同样弹卡。

## 它做什么（顺序固定）
前置检查（卷表、部件、输出目录、`cuts.json` 形状与窗口校验、空闲空间；不过退 2，什么都不建）→ 截断点（`build_timeline` 的旁白终点 + 余韵，不写预测值）与保留窗口 → 每卷 3 秒封面过场卡 → 截尾与中段切除件生成 → 流签名逐项比对（以第一卷为基准，不一致退 1）→ concat 无损拼接 → 自证（总长 = 部件之和、全片解码零报错）→ `04-assembly.json` 部件账本 → `07-chapters.txt` 章节清单（若任意成员卷声明了 `## 章节`）→ `pipeline.qc`。

- **关键帧局部重编**：保留窗口总长 ≥ 20 秒的 H.264 卷优先按源帧网格量化并在关键帧处做局部重编（主体保留区间通过 `-c:v copy` 拷贝、校验关键帧首包大小及各分段包数，去掉 `-shortest` 防尾部丢帧，仅对切口与淡出前后数秒重编码并与源流 `time_base` 对齐，完成后即时清理 `splice_*` 中间目录）；当源片非 H.264、关键帧分布不足、包校验未对齐或子段编码失败时，均自动回退全段重编码路径。
- **人定删减顶栏重算**：含 `_agent/hud_clean_top.mp4` 净画面顶条的成员卷，若删减窗口（`cuts.json` 或 `余韵N秒`）触及章节顶栏区间，总装自动将章节与子节投影到保留窗口、用净条带遮盖原顶栏并重烧新顶栏（保留底部既有人声字幕）；仅裁去 `vo_fg_end` 之后纯音乐余韵的卷跳过重烧，继续走关键帧局部重编。
- **合集章节清单**：当任意成员卷的 `02-script.md` 声明了 `## 章节` 时，总装按过场卡（3 秒）与 `cuts.json` 保留窗口自动换算每卷章节与子节的偏移时间（章首被切而章尾保留时自动贴到缝口起点，仅落入淡出带内的残章剔除），在输出目录原子写出 `07-chapters.txt`；该旁路产物若因事后成员稿件异常生成失败仅记警告并继续 `pipeline.qc`。

## 红线
- **不重配 TTS、不重渲分期主体**：只截尾或原样拼接。
- 自证没过、或总装途中某卷成片被改动 → 退 1，旧成片原样保留、不写账本。
- 退 3 = 另一个总装正在用同一个输出目录，等它跑完。
- 成片交人前至少听一遍各章节交界。
