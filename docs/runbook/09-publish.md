# Runbook: 09 人工发布（停机点 4）

【🛑 强制人工停机点】：最终把关与全网分发。

## 输入物
- 最终成片：`data/episodes/<期号>/05-final.mp4`
- 定稿封面：期目录顶层 `08-cover.jpg`（横版）与 `08-cover-vertical.jpg`（竖版），来源是 `07-cover/` 里人点名的那一版
- 标题、简介、标签：`data/episodes/<期号>/07-titles.md` 的 `## 定稿标题` / `## 简介` / `## 标签`
- 上面缺哪项，`read_status` 的 09 会列出来（D90）；见 [08 交付物](08-cover-title.md#交付物09-前必须齐read_status-逐项核对)

## 人工操作（耗时约 3 分钟）
1. 核对顶层横竖两版定稿封面，与 `07-titles.md` 的定稿标题、简介、标签；
2. 在桌面端批 09（填 `07-cover/` 里定稿那一版的路径与标题原文）；
3. 手动上传至目标视频平台（B 站、YouTube 等）。

> **ack 携带定稿（Spec 12）**：第 09 停机点的批准必须给出封面路径与标题原文（app 的 09 卡两个输入；**封面填 `07-cover/` 下的那一版，如 `07-cover/edit-6.png`，填顶层 `08-cover.jpg` 会被拒**；终端 `ava <期> /approve 09 --id <id> --cover <路径> --title <标题>`），core 会在批准时刻自填文件大小与 `mtime_ns` 供事后审计——发布动作仍在 ava 之外。

## 核心规程与铁律
- **坚决不做自动上传**：省下两分钟不值得拿核心账号安全与平台风控冒险。
- 交付清单齐了、人手动上传完成，本期才算闭环。清单以 `read_status` 的 09 缺项为准，没齐不说「闭环」「做完了」「可以批准 09」。

## 09.2 发布合规与版权守则

- 二创混剪 + 原创口播属灰区，加口播是加分项；**纯搬运不做**。
- **BGM 用该番自己的音乐**（OST / OP / ED / 插曲 / 角色歌）。例外须人拍板并在 `config/bgm.json` 的 `from` 里写明来源与理由（2026-08-12 已立一例：罪恶王冠选用了 EGOIST 的 `Last Song -Instrumental-`，出自 Bravely Second 单曲碟，非本番曲目——因该曲是本期主题的感情落点，人耳现选时拍板）——例外不留默认权，每次都要人点头。
- **上传手动做，不自动化**——省下的几分钟不值得拿账号冒险。
- 片源不进 git、不外传。
- **小样本结论，不是通则**：换平台、换账号规模、或平台改检测策略，这条就可能失效——重新验，别照搬。
