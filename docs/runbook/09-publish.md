# Runbook: 09 人工发布（停机点 4）

【🛑 强制人工停机点】：最终把关与全网分发。

## 输入物
- 最终成片：`data/episodes/<期号>/05-final.mp4`
- 封面图库：`data/episodes/<期号>/07-cover/`
- 标题候选：`data/episodes/<期号>/07-titles.md`

## 人工操作（耗时约 3 分钟）
1. 从 07-cover/ 中挑选 1 张视觉冲击力最强的封面图（可加微标/主标字样）；
2. 从 07-titles.md 挑选（或微调）1 条最契合本期分发的标题；
3. 手动上传至目标视频平台（Bilibili、YouTube 等）。

## 核心规程与铁律
- **坚决不做自动上传**：省下两分钟不值得拿核心账号安全与平台风控冒险。
- 发布完成即标志本期生产闭环。

## 09.2 发布合规与版权守则

- 二创混剪 + 原创口播属灰区，加口播是加分项；**纯搬运不做**。
- **BGM 用该番自己的音乐**（OST / OP / ED / 插曲 / 角色歌）。例外须人拍板并在 `config/bgm.json` 的 `from` 里写明来源与理由（2026-08-12 已立一例：罪恶王冠选用了 EGOIST 的 `Last Song -Instrumental-`，出自 Bravely Second 单曲碟，非本番曲目——因该曲是本期主题的感情落点，人耳现选时拍板）——例外不留默认权，每次都要人点头。
- **上传手动做，不自动化**——省下的几分钟不值得拿账号冒险。
- 片源不进 git、不外传。
- **小样本结论，不是通则**：换平台、换账号规模、或平台改检测策略，这条就可能失效——重新验，别照搬。
