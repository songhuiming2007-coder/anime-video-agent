# Runbook: 05 审时间码（停机点 3）

【🛑 强制物理停机点】：整条流水线唯一拥有硬阻断的人工质量闸门。未经 approve，渲染器拒绝启动。

## 核心操作
1. **生成并打开审看页**：agent 跑 `review`（期目录自动补上；模型发起的 review 不许带任何选项），桌面端预览区打开 `04-review.html`（停机点就绪时自动打开）。
2. **人类审查要点（约 5 分钟）**：
   - 抓**“台词对了但画面不对”**：排查画外音错配（台词在说话，但镜头切给了路人或非在场角色）；
   - 检查片段抽帧（入点、中点、出点）是否平滑，有无切断关键动作。
3. **批准封板（显式动作）**：人在桌面端决策条点 05「批准」（或终端 `/approve 05`），产出 `04-clips.approved.json`。底层等价 `python -m pipeline.review <期> --approve`，只作排查参考。
   - **有补丁段时**（外部素材 / 补丁池画面）：点「批准」会先弹一个确认框，列出补丁段的段号，确认后才批准，取消则什么都不写（D89）。终端里批准要加 `--confirm-patch`；没有终端可作答时（管道、作业）`review` 会直接拒绝，不再卡在 `input()` 上。

## 普通期在这里定 BGM
配音出来、画面排好之后，人听过才知道该配什么：人点名曲库里的文件和用法（循环、几首接续），agent 写进 `01-topic.md` 的 BGM 字段；稿件里有任何 `## 音乐段`（比如试看段）时，BGM 只认稿件里的块，按 `skills/write-script/SKILL.md` 8.3 写铺底块。人没点名，agent 不选曲。企划期的音乐与文案一起设计，见 `config/agent/scopes/project.md`。

## 产物与铁律
- 产物：`data/episodes/<期号>/04-clips.approved.json`
- **铁律**：批准必须是人看后的显式动作（决策条或 `/approve 05`）。**Agent 不能跑 approve**——`review` 带任何选项在弹卡前就被拒（ADR-0020 §3）。无 approved 文件后续渲染立即报错退出。
