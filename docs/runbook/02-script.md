# Runbook: 02 脚本写作与机检

Agent 驱动撰写口播与分镜，并通过自动化静态机检。

## 产物与位置
- `data/episodes/<期号>/02-script.draft.md`（原始草稿）
- `data/episodes/<期号>/02-script.md`（机检与待审终稿）

## 执行步骤
1. **调用技能写稿**：调用 `skills/write-script`，参考 `01-topic.md` 与题材骨架，写出 8–20 个微单元段落。
2. **段落规范**：每段必须明确包含配音文本、`查询:`（台词语义）或 `锚点:`（具体时间码）。
3. **运行机检**：agent 跑 `check_script`（免卡，期目录与稿件自动补上）。底层排查参考：`python -m pipeline.check_script data/episodes/<期号>/02-script.draft.md`。

## 核心规程与铁律
1. **查询是机器接口不是构图备注**：`查询` 文本会原样进入字幕向量检索，写“角色承认逃避”有效，写“中景逆光”必落空。
2. **机检全绿方可交工**：必须满足单句字数、气口起伏、剧情锚点数与禁词门限（机检条数随判据迭代增减，不写死——以 `check_script` 实际输出为准）。
3. **机检过后跑 02.8 对抗审查**（2026-10-09 人裁决，D48 ②）：`run_pipeline adversarial`（弹卡）。一个看不到写稿对话的审查者，只拿稿件、番剧笔记与逐段锚点窗口内的字幕、在场索引，挑三类问题：**事实**（错误与模糊）、**衔接**（转折不畅）、**语言**（AI 味太浓、语病），写 `02-adversarial.md`。它的引用会被机械核对，核不上的标 ⚠。
   - 事实类：逐条查证（整集台词 → 在场索引 → 笔记），成立的改草稿，在报告终审表填「采纳 / 驳回 + 理由」（写 `02-adversarial.md` 弹卡）；标 ⚠ 的先当它没说。
   - 衔接、语言类：**只诊断不改写**，不自己动稿，原样转给人，终审表留「人定」。
   - 不拦：没跑也能进 02.5，状态卡会提示「02.8 对抗审查还没跑」。
4. **挂起停机点**：原样复制生成 `02-script.md`，**立即停机**，移交人工总监审稿，进入 `02.5`；交稿时说一句报告里还有几条衔接 / 语言问题待人定。
