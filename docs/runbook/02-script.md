# Runbook: 02 脚本写作与机检

Agent 驱动撰写口播与分镜，并通过自动化静态机检。

## 产物与位置
- `data/episodes/<期号>/02-script.draft.md`（原始草稿）
- `data/episodes/<期号>/02-script.md`（机检与待审终稿）

## 执行步骤
1. **调用技能写稿**：调用 `skills/write-script`，参考 `01-topic.md` 与题材骨架，写出 8–20 个微单元段落。
2. **段落规范**：每段必须明确包含配音文本、`查询:`（台词语义）或 `锚点:`（具体时间码）。
3. **运行机检**：
   ```bash
   python -m pipeline.check_script data/episodes/<期号>/02-script.draft.md
   ```

## 核心规程与铁律
1. **查询是机器接口不是构图备注**：`查询` 文本会原样进入字幕向量检索，写“角色承认逃避”有效，写“中景逆光”必落空。
2. **机检全绿方可交工**：必须满足单句字数、气口起伏、剧情锚点数与禁词门限（机检条数随判据迭代增减，不写死——以 `check_script` 实际输出为准）。
3. **挂起停机点**：机检通过后，原样复制生成 `02-script.md`，**立即停机**，移交人工总监审稿，进入 `02.5`。
