# M2b 修正清单：服务对象从「番剧域」改为「素材池」

日期：2026-09-11
状态：**待 M2b 施工 session 执行**
依据：ADR-0015（VLM 意象文本化）、ADR-0003（视觉索引作筛子）、ADR-0008（番剧笔记锚点）、ADR-0016（端云解耦）
来源：用户 2026-09-11 对六个问题的裁决（本文件是执行版本，裁决理由逐条保留）

---

## 为什么有这份修正

M2a 施工期间浮现的理解偏差：**M2b 的主要服务对象是真实素材（Live/MV/采访/扫图），不是番剧。**

番剧排片根本不需要视觉索引 —— 它走**番剧笔记的分钟级 Ground Truth 锚点**
（ADR-0008 实测 18/18 段命中剧情关键分镜）。真实素材没有笔记、没有字幕，
字幕检索覆盖率 0%，视觉索引是它**唯一**的排片依据。

当前实现里的措辞与配置结构都假设了番剧域（例如 `vprobe.scene_probe` 的
「要判的是『这套索引认不认得**动漫画面**』」），需要按下面六条对齐。

---

## 一、验收判据改口径：实拍为主，番剧降为参照

- 「认不认得动漫画面」→ **「认不认得实拍画面」**。
- 30 镜头抽验来源从罪恶王冠改为 **EGOIST SP 池**（SP01~08 就是 Live 实拍）。
- **番剧域不删，降为参照组** —— 理由见第四题（两域各标一次，数值若收敛，
  「门槛能否跨域合并」这个元问题就有了实测答案）。

**改哪里**：`pipeline/vprobe.py` 的 `scene_probe` docstring；`docs/` 里引用该判据的地方。

---

## 二、SP 键是伪阻塞 —— 已核实，零改动

核实结果（2026-09-11 在盘上验过）：

| 断言 | 证据 |
|---|---|
| `shots.build()` 原生支持 SP 键 | `pipeline/shots.py:154-156`，`season=None → f"SP{episode:02d}"`，注释明写「season=None 是 SP 特典集（ADR-0010 决策二）」 |
| EGOIST SP 镜头表已存在 | `data/library/shots/EGOIST_SP01.json`（37KB，**159 个镜头**）+ SP02/SP03… 均在盘 |
| 寻址与番剧集键同构 | `build()` 与 `load()` 都走 `load_sources(anime).get(_key(season, episode))`，同一张 `sources.json` |

**结论**：`build_captions("EGOIST", "SP01")` 大概率**零改动直接工作** —— 但要**跑一遍实测确认**，
不许停在「大概率」。

**不做的两件事**（YAGNI）：

1. `(anime, key)` 参数形态**不改**。「anime」这个名的真实语义是「素材池」——
   那是**词汇问题不是接口问题**，在注释里说清即可，不动签名。
2. **不建**「固定间隔切分」的 fallback。采访类几十秒素材 scene detect 可能只切出
   1~3 个镜头，**captions 照跑，粒度粗不是错**。真撞到「低运动视频切不动」再建。

**未来新素材的路径**（M2.5 接续）：`acquire register --as SP09` → `shots build` →
进同一个键系，无需新机制。

## 三、门槛按素材池存

`config/scenes.json` 现有的按番分组**原样保留**，**池条目与番条目同级平铺**：

```json
{
  "春物":     {"queries": [...], "negative": [...]},
  "罪恶王冠": {"queries": [...], "negative": [...]},
  "EGOIST":   {"queries": [...], "negative": [...]}    ← 池，与番同级
}
```

**不共用、不按类型合并。** 配置文件自己那句警告已经证明门槛是**域条件**的：

> 「太空中的宇宙飞船」在春物里不可能出现，在科幻番里是正片，照搬会把噪声地板
> 测成一个真命中的高分，门槛跟着定高，于是真实查询大面积判 no_match。

同理：Live 舞台（荧光棒海 / 追光 / 烟雾）与采访（室内固定机位）的 caption 分布不同。
**共用门槛就是拿春物的尺子量 EGOIST，同构错误。**

---

## 四、标定不迁移，逐池各标定一次

**理论依据（要说透）**：门槛活在**文-文侧**（bge-m3 向量空间），**不在画面侧** ——
所以「二维作画 vs 光学成像」这个差异**不直接冲击门槛**。

**但不能因此假设可迁移**：caption 的**词汇与文体分布**随素材域变化，分布变了噪声地板就变，
「可迁移」是**假设不是事实**。

**而标定成本极低**：10 条反例查询 + 几分钟。**便宜到不值得赌迁移。**

**罪恶王冠的标定保留，但角色变了**：它不再是「为迁移做代理」，而是**番剧域参照点**。
两个域各标一次之后：

- 若数值**收敛** → 「门槛能否跨域合并」这个元问题有了实测答案（收敛则以后合并）
- 若**不收敛** → 证明逐池标定是必须的

**S2 原则：数据没齐不定标准。** 现在不许先合并，也不许先断言不可合并。

---

## 五、显式触发；成本闸改口径，但不拆除

1. **显式命令，不自动触发。** 入库是本地动作，打标要云端 GPU —— 自动触发会把本地流程
   耦合到开机，违反 ADR-0016 的解耦，也违反「入库最后一公里显式」的哲学。
2. **成本闸单位从「单季」改为「单次运行预估额」**：captions 运行前打印
   （镜头数 × 单镜头成本），超 ¥25 阈值才要 `--confirm-cost`。几十秒素材镜头数少，
   预估自然远在闸下。
3. **闸门保留** —— 它防的是「手滑对一部 3 小时 Live 全集跑打标」这种**量级错误**，
   与素材长短无关。

**改哪里**：`vindex.estimate_caption_cost` 的调用与打印口径（函数本身已按镜头数算，
主要改提示语与闸门比较的表述）。

## 六、`clips.py` 不需要新分支

**现有阶梯已经内建了这个分流**：

```
锚点直通（有番剧笔记时间码）
  → 字幕检索（有台词）
    → 场景检索（兜底）
```

真实素材**没有笔记也没有字幕**，前两级自然落空 —— **空结果是数据不是错误**，
阶梯自动落到场景层。这正是 ADR-0003「索引作筛子」的既有机制。

**数据决定路径，不声明素材类型。**

**唯一要改的**：场景索引的**加载按池寻址**（与第三题是同一件事）。

**封印机制不变**：`scenes.json` 里有该池的门槛 = 解封。

## 执行顺序建议

1. **先跑实测**（第二题）：对 `EGOIST SP01` 跑一遍 `vindex captions`，确认零改动可用。
   这是唯一的硬验证点，其余都是措辞与配置结构。
2. 措辞对齐（第一题）：`scene_probe` docstring 改「实拍画面」。
3. 配置平铺（第三题）：`scenes.json` 加 `EGOIST` 池条目，与番同级。
4. 标定（第四题）：对 EGOIST 池跑 `vprobe scene`，罪恶王冠保持参照不删。
5. 成本闸口径（第五题）：改提示语。
6. 复核 `clips.py` 零分支（第六题）：确认无需改动，只在文档里记一笔。

## 本清单不涉及的事

- **不改任何已有代码签名**（`(anime, key)` 保持）
- **不删番剧域**（降为参照组）
- **不建 YAGNI 机制**（固定间隔切分）
- **不动 `shots.py`**（SP 支持已存在）
