# 参照基线：人类文本量出来是什么样

`check_script.py` 里那几个节奏阈值的依据。**改那些数字之前先读这里，并且拿新样本重量一遍。**

存在的理由：这个项目的每一条阈值都被实测推翻过至少一次。08-03 加的「气口段均长 ≥11 字」
只活了一天——因为它当初是拿**一篇**参照样本定的。一篇样本定不出阈值。

## 量法

```bash
# 参照样本（任意纯文本，整个文件当正文）
python -m pipeline.check_script --raw <样本.txt>...

# 本期稿子（只取「配音：」行）
grep -h '^配音' 02-script.md | sed 's/^配音：//' > /tmp/vo.txt
python -m pipeline.check_script --raw /tmp/vo.txt
```

判定用的口径和 `--raw` 完全同一份代码，所以基线和门禁不会各说各话。

## 结论

**一、分得开的是起伏，不是长度。**

句长 CV（变异系数，业界叫 burstiness）：人类 11 篇里 10 篇 ≥0.55，三期 AI 稿全部 <0.55。
阈值取 0.55。

**注意第三期是三期里最均匀的一篇（0.34）。** 08-03 那次修改把气口均长从 8.2 拉到 11.9，
方差却掉了——**它把平均值调对了，把起伏调没了**。人听出来的「不管换什么话题都一个样」，
量出来就是这个 0.34。

**二、气口段均长不区分好坏，那道门禁是误诊。**

赞数最高的两篇（30400、18399）气口均长只有 7.1 和 7.5，比三期 AI 稿还短，
会被 08-03 加的「≥11 字」判 FAIL。它惩罚的是短句多的文风，不是机器味。已删除。

**三、三期稿子一句长句都没有，而这是机检自己造成的。**

`max_sentence = 40` 把上限焊死在 40，于是「超 45 字句占比」必然是 0%。
人类样本这一项是 0–43%（中位约 27%）。已改成 90，换气约束交给 `max_breath = 30`。

**四、量过但分不开、因而不设门禁的两项。** 记在这里是为了下次不要有人再去加：

| 量 | AI 稿 | 人类 | 为什么不设 |
|---|---|---|---|
| 「不是 X，是 Y」等否定平行结构 | 0.22–0.37 /百字 | 0–0.47 /百字 | 人类里最高的一篇比三期 AI 稿都高。**分不开就不许当门禁**——它是写法问题，写进 SKILL.md 当判据 |
| 语气词密度（啊/吧/嘛/哇…） | 0–0.33 /百字 | 书面体约 0.1，口语体 1.21 | 看着差很远，但口语体样本**只有一篇**。样本量到之前不立规矩 |
