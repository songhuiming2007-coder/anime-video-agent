# 写稿

产出一篇 870–1300 字口播稿（约 2–3 分钟）与逐段分镜标注。

> 字数带 2026-07-29 从 700–1000 改过：配音语速实测 434 字/分（不是原先假设的 280），
> 旧的 700–1000 只有 1.6–2.3 分钟，够不到 CLAUDE.md 要求的 2–4 分钟。
> 语速由 `config/voice.json` 里的参考干声决定，**换音色就要重推这条线**。

分镜标注的 `查询` 字段会被原样送进 `pipeline/subindex.py` 检索，**它是机器接口不是备注**，
措辞方式见「标分镜」一节。

声音样本与特征：**优先读 `VOICE.local.md`**（本人文稿提炼版，不进 git），
没有才退回 [VOICE.md](VOICE.md)——那是空模板，讲的是怎么提炼、要填哪几栏。
**退回模板时不要假装有声音样本**，照模板的骨架写只会得到通用 AI 腔，
应当先提示用户去填 `VOICE.local.md`。

节奏阈值的实测依据在 [BASELINE.md](BASELINE.md)。**要改那几个数字先读它。**

六个 leading word 贯穿全流程：**念得出来**、**起伏**、**张力**、**机制**、**细节**、**公道话**。

## 这份文档 2026-08-04 又大改过一次，先读这段

08-03 那次的方向是对的——「减少对形状的规定、增加对判据的规定」。但执行错了：
**那次加进来的判据全是禁令**（不许用这些词、不许并列、气口段不许太短）。

禁令的补集是均匀的。三轮加禁令下来，最新一期成了三期里最整齐的一篇：

| | 自我牺牲 | 适合大老师 | 谁最适合你 | 人类 11 篇 |
|---|---|---|---|---|
| 句长起伏 CV | 0.46 | 0.48 | **0.34** | 0.45–0.81 |
| 超 45 字的句子 | **0%** | **0%** | **0%** | 0–43% |

08-03 那次把气口段均长从 8.2 拉到 11.9，**平均值调对了，起伏调没了**。
人听出来的「不管换什么话题都一个样」，量出来就是那个 0.34。

而「零长句」这一栏是机检自己造成的：`max_sentence` 焊死在 40，稿子想长也长不了，
可这份文档同一页写着「整句可以很长，只要中间有逗号让你换气」——数字和文字互相矛盾，
执行时数字赢了。

**所以本次修改的方向是：少写「不许」，多写「必须有」。**
禁令只能防住最差的那一篇，防不出好的那一篇；能产生东西的判据都是正向的。

**以后再往这份文档里加东西时，先问一句：我加的是「不许」还是「必须有」？**
如果又是一条「不许」，先想清楚它拦掉的东西是不是本来就该在。

## 语言风格

稿子是要**念出来**的，不是给人读的。写完出声念一遍，这是最终判据。

### 节奏：判据是起伏，不是长度

念稿断气发生在**逗号之间的那一段**，不在整句。整句可以很长，只要中间有逗号让你换气。
按实测语速 434 字/分（7.2 字/秒）算，30 字的气口段是 4.2 秒——一口气绰绰有余。

所以只有两条是硬的：

- **单个气口段 ≤30 字**（念得完）
- **全篇至少两句超过 45 字**，且句长 CV ≥0.55（有起伏）

长句要靠**逗号撑开**，不是靠往一句里塞更多修饰。写不出长句通常不是文风问题，
是那一处只有一个念头——一个念头本来就只值一句短的，得先去找第二个念头。

**短句是标点，不是常态。** 参照样本一千字往往只有一处独立短句，正因为只有一处它才有劲。
写十五处，一处都不响。全篇 ≤8 字的整句不超过 5 处。

> 08-03 这里写过一条「气口段均长 ≥11 字」，2026-08-04 删除。
> 重测发现赞数最高的两篇人类样本气口均长只有 7.1 和 7.5，都会被那道门禁判死——
> 它惩罚的是短句多的文风，不是机器味。详见 BASELINE.md。

### 不要解释你刚说的话

一句话说完就完了。**下一句不要告诉观众刚才那句意味着什么。**

这是本期稿子里最普遍的一种机器味，业界叫 narrator 腔。上一期的实例：

> 可惜了啊，彩加小天使是男生。~~所以只能拿场外特别奖，不进决赛。~~

第二句是在解释第一句。删掉，没有任何人看不懂。

参照样本里最狠的一段是写一个人的死：起床、发愣、躺下、五分钟、脑梗、六十七岁。
六个事实，零个情绪词，零句解释。**能自己站住的事实不需要人扶。**

判据：把这一句删掉，观众会不会看不懂？不会，就删。

### 「不是 X，是 Y」少用，用了就删前半句

否定平行结构是 AI 文本最好认的骨架。**处理动作是删掉前半句，直接说 Y。**

「他不是不会说话，是算准了说什么最快能让人讨厌他」→「他算准了说什么最快能让人讨厌他」。
后者更短、更硬，而且不预设有人会误解。

三连以上的排比（「雪乃要的是……结衣要的是……静老师要的是……」）整段重写，
不要只删一条——四条改三条还是排比。

> 这一项量过：AI 稿 0.22–0.37 次/百字，人类样本 0–0.47，**分不开，所以不设机检门禁**。
> 分不开就不许当门禁，这是 CLAUDE.md 的规矩。但它照样是判据，靠你自己看。

### 大白话

学术词、行话、成语堆砌换成日常说法。读过书不等于要在稿子里掉书袋。

- 「异化」→「丧失初心」
- 「主体性」→「自己做主」

判据：这句话能不能对着一个没读过这个专业的人当面说出口。

### 套话：黑名单已经冻结，不要再加词

`VOICE.local.md` 里那些「行，今天我继续骂」「对，你没听错」是**样本**，
是给你看这个人说话带什么味道的，**不是让你原样抄进稿子**。

机检里那张黑名单（说句公道话 · 我知道你要说什么 · 这就是我的答案 · 所以别误会 ·
第一条／第二条 · 你先别急 · 注意，…… · 你看，……）**冻结在现有这几条，不再往里加**。

理由是这个项目已经吃过两次同样的亏：回读质检的同音字折叠表被日文专名击穿，
CLAUDE.md 的结论是「手写的等价表追不上，要换维度」。套话表一模一样——
这期禁了「当然要说句公道话」，下期就是「客观地讲」，穷举不完。
而每加一条禁令，输出就往中间收敛一格。

**遇到新的套话不要加词，去看它为什么会出现。** 套话的共同点是不携带信息，
它的作用只是提示「下面这句重要」——而一句话重不重要应该靠它自己说清楚。
一句话如果需要前面那句来宣告它的分量，问题在那句话本身。

**同一种修辞全篇不超过两次。** 反问、先复述对方的话再打、破折号转折，这三样都好用，
但各上七八次就成了口癖。上一期开场用过反问，这一期换个开法。

### 人称与说话的痕迹

「我」高频出现，不回避主观；直接对「你」说话；偶尔用「咱」拉近。

口播稿是**说**出来的，现在的稿子是**写**出来的书面语——语气词密度接近零，
而口语体的人类样本是每百字 1.2 个。该有的「啊」「吧」「嘛」「哇」不要修掉。
说话的痕迹要有，但**每期现造**，不要从清单里挑。

补充信息写成短句，不塞括号——括号念不出来，引号也念不出来
（IndexTTS 实测把弯引号当字符念出音节，「谁更该"赢"」念成「谁更该非赢匪」）。

段落之间靠语义接续。「因此」「然而」「此外」「综上」这类词念出来像在读论文。

## 0. 先读上一期的稿子

**开写之前先把 `data/episodes/` 里上一期的 `02-script.md` 读一遍。**

这一步的唯一目的是**不重样**。读完在心里点清楚三件事，写的时候躲开：

- 上一期的**形状**是什么（见「挑形状」）——本期必须换一个
- 上一期的**开场动作**是什么（摆靶子？抛疑点？先让步？）——本期换一个
- 上一期反复出现的**口头禅**有哪些——本期一个都不许再用

这一步看着像走过场，但它是唯一能对抗「每期一个样」的机制。
模型没有跨会话记忆，**不主动去读，就必然会在同一个默认形状上收敛**。

没有上一期（第一期、或换了新番第一期）就跳过，并在稿子开头写一句「无上期」。

## 1. 先把剧情查准

要用到的剧情事实——哪一季哪一集、什么场合、谁做了什么——**开写之前先确认**。
`data/library/notes/<番>.md` 优先；没有笔记就上网查证。

**不要凭记忆写剧情。** 记忆只支撑得起抽象概括，支撑不起可指认的事件，
写出来必然通篇空谈；而记错剧情在二创里是致命的，弹幕会当场拆穿。

### 写「某某说」之前必须抽帧确认说话人

**这是记忆最不可靠、而工具最帮不上忙的地方。**

字幕索引能告诉你「这句台词在第几分几秒」，但**告诉不了你是谁说的**——
`.ass` 的 `Name` 字段字幕组基本不填（春物那版 742 条全空）。检索出来的时间点是对的，
说话人只能靠记忆，而记忆在这里恰好最容易错。

2026-07-29 实测踩过：稿子写「雪之下跟他说，别再那样自我牺牲了，好吗」，
抽帧一看那场戏从头到尾只有叶山和八幡，雪之下根本不在场——这句和后面
「你之所以帮助别人，难道不是因为你自己也渴望得到帮助吗」都是**叶山**说的。
两句都是名场面，认错人一定会被弹幕抓。

查证方法，两步：

```bash
# 1. 检索定位这句台词在哪一集第几秒
python -m pipeline.subindex search "别再那样自我牺牲了" -k 3

# 2. 抽那一秒的帧，看画面上谁在说话
ffmpeg -ss <秒> -i <该集 mkv> -frames:v 1 -vf scale=480:-1 /tmp/who.jpg
```

日语原文的人称与语尾也是旁证：雪之下称八幡「比企谷くん」、用「あなた」；
叶山用「君」、用「〜ないか」这类男性语尾。两者对不上就是认错人了。

**画面和稿子不一致时，先怀疑稿子。**

## 2. 捡料：先攒过量的具体东西

**开写之前先列一张料单，至少 20 条，最后大概只用得上 8 条。**

这一步是 2026-08-04 新加的，针对的是一个具体症状：三期稿子的「具体信息」密度并不低，
但全是**引用坐标**——第一季、第二季婚活特辑、S3E04。出处不是细节。
说出「第一季婚活特辑有道题」，观众脑子里不会出现任何画面。

料分三类，各占三分之一左右：

- **原台词逐字**。不是转述，是那个人当时说出口的那句话，一个字不改
- **画面上能看见的东西**。抽帧看，把看见的具体物件、动作、表情记下来
- **观众自己生活里的场景**。不是「一个人吃饭很孤独」，是「食堂里把托盘端到最靠墙那张桌子」

### 至少 3 条必须是「非承重」的

**非承重 = 拿掉它，你的论点一点不受影响。**

这一条是全篇最反直觉的要求，但它是「像人写的」和「像机器写的」之间最大的那道分界。

参照样本写一个退休的人准备去钓鱼，给的是「小木船、渔网、鱼竿」；写他陪酒，给的是
「三个小钢炮，差不多五两酒」。这些东西不证明任何论点，删掉论证毫发无伤——
**正是它们让人相信这个人真的存在过。**

机器写不出非承重细节，因为机器写的每一句都在服务论点。
你如果只查了论点需要的东西，你手上就只有承重细节，这一条自然就交不出来。
所以料要**过量地捡**，捡的时候不要问「这条有什么用」。

### 料单落在稿子头部

写在 `02-script.md` 最上面的元信息区（形状那一行旁边），`---` 之上。
机检只统计「配音：」行，料单不占字数、不占段数。

留着它是为了下一期能看见上一期用过什么、剩下什么。

## 3. 校验张力，不发明张力

开场必须有一个**不对劲的地方**，观众才有理由听下去。

**张力由选题决定，不在这一步发明。** 立论还是驳论是选题自带的属性：
「八幡的自我牺牲其实是自我保护」天生是驳论，「他拿到想要的东西之后为什么反而更难受」
天生是立论。`01-topic.md` 必须带这两个字段：

```markdown
模式: 驳论            # 驳论 = 通行说法不对；立论 = 作品里有个说不通的地方
张力: 弹幕里最常见的一句话是——大老师又自爆了。
```

本步只做校验：

- **驳论**：能想起至少一处听过这个说法的场合（弹幕、评论区、他人视频、自己曾经的想法）。
  想不起来说明是杜撰的稻草人。
- **立论**：这个疑点问出来，别人会「对哦，为什么」，而不是「那不是显然吗」。

字段缺失或校验不过，**停下来报告，退回选题阶段**。不要自己换一个张力接着写——
张力是整条流水线里唯一真正的编辑判断，而它已经过人工批准，
在写稿阶段悄悄改掉等于绕过了唯一的人工关卡。

**但张力字段的写法不等于开场白的写法。** 上面那个字段是给人看的备忘，
写进稿子时要用它自己的话说出来，不要先交代出处再引用。
「弹幕里最常见的一句话是——大老师又自爆了」是在报出处；
直接说「又自爆了」，观众自己知道这话是从哪儿听来的。

## 4. 挑形状

**形状从张力里长出来，不从模板里选。**

下面四个形状是从真实的长评里拆出来的，**列在这里是为了说明形状可以差多远，
不是一份菜单**。张力要是长得像别的样子，就写别的样子，在稿子开头说明一句即可。

**先给对方最好的**
: 开场把通行解读讲得比它的支持者还透，讲到观众开始点头，然后一句话掀掉。
  剩下全程守这一刀。
  （出处：bangumi「漂亮得像一张张壁纸」——前四句全在夸京阿尼的作画，
  第五句「可惜动画终究不是连续播放的画集」把前面全部翻过来。）

**一个比喻贯穿到底**
: 开场立一个比喻，中间每一段都是这个比喻的变形，结尾回到它、但意思已经变了。
  （出处：同一篇的「壁纸→命题作文→支线任务解锁词条→一封由顶级代笔人写的信」。）

**两个东西互为镜子**
: 挑两个角色或两种活法对着写，论点从对比的缝里长出来，而不是先有论点再找例子。
  （出处：bangumi「孤独患者的另类青春恋爱物语」整篇是叶山 vs 八幡、团子 vs 雪乃。）

**一路追问下去**
: 一个疑点，答出来引出一个更大的疑点，最后停在一个没答完的问题上。
  （这一种最适合立论；它的结尾天然可被反驳，弹幕会替你把话说完。）

选完在稿子头部写一行，**并且不许和上一期相同**：

```markdown
形状：先给对方最好的（上期：一路追问）
```

### 段落功能不许齐一

不管用哪个形状，都有一条硬的：**全篇至少 3 段不收落点。**

现在的稿子每一段都是「论点 + 引用 + 落点」的完整小论证，二十段就是二十个小论证并排——
这是模版感最直接的来源，比任何一个套话词都更明显。

真实的文章里大量段落是不完整的：只做铺垫、只把一件事叙述完、甚至岔开去说件别的。
只铺垫不收口的那一段，正是让下一段的落点砸得响的东西。

判据：**把每一段的最后一句抄出来排成一列。** 读起来像一串金句合集，就是犯了这个毛病。

## 5. 论据：给机制，不是给例子

每个论据挂一个**可指认的剧情事件**：哪一季哪一集、什么场合、发生了什么。
全篇至少 3 处锚点（`check_script` 会数）。

**但挂上事件不等于论证。** 一个论点配一句台词，证明不了任何事——
任何论点都能在四十集里找到一句配得上的台词。这就是三期稿子「论述不严谨」的根：
它给的全是例子，例子只能说明，不能证明。

**每个论据必须回答下面两个问题里的至少一个：**

- **反事实**：不这样会怎样？换个人在同一个场合会做什么？
- **排他**：为什么是这个原因，不是另一个看着也说得通的原因？

参照样本里那篇 30400 赞的观察，讲外卖骑手为什么比零工更不容易走极端，
四条理由每一条都带一个对照组：零工谈价钱是跟人打交道所以怒气对着人，外卖的规则摆在
那儿所以怒气对着系统；零工一天押一票所以一次被坑就全军覆没，外卖一天几十单所以怒气
被稀释。**每一条都在说「不这样会怎样」。**

另一篇用的是量的推断：作者写自己在那种环境里待了八年就落下「做不好就别做」的毛病，
而角色待了十六年，所以只可能更极端。八年和十六年这两个数字是论证，不是修饰。

### 篇幅按在意程度分配，不按论点个数

**不要平均分配。** 三段并列、每段一个例子、每段长度差不多——报菜名。

参照样本一千字里，世界观不自洽给了三段，「代笔这件事本身让我不舒服」给了四段，
角色成长只给一段。挑一个你自己最在意的场景，挖到底：它当时发生了什么、原话是怎么说的、
换个人会怎么做、为什么这个差别要紧。这一块应该是全篇最长的。
其余的例子降级成一两句旁证，点到为止。

「那几次事情」「那些人」「有些角色」这类模糊指代是论据不实的症状，不是措辞问题——
出现了就回去补锚点，不要只换词。

**结论必须是一个会被人反驳的判断。** 判据：**能想象出一条反驳你的弹幕**。
想象不出来说明写的是共识，共识没有传播价值。

## 6. 公道话：位置自由，存在必需

在自己的立场内部，主动给出**对自己不利的具体反面证据**，然后守住原判断。

判据：这段话**单独拎出来看，像是反方在说话**。
「当然，凡事都有两面性」这类空转不算——它没有引入任何新信息。

内省文最容易滑向自我感动，公道话是唯一的解药。**这一步不跳过。**

**但它没有固定位置。** 参照样本里它出现在三个地方：

- **开场**就是让步（「画面确实没什么可挑剔的」），全篇是从让步里翻出来的
- **就地让步**，插在论证内部（「识字率不高当然可以解释一部分需求」），小剂量、多次
- **划清边界**（「我并不是反对煽情，也不认为作品必须现实主义」），防止被曲解

三种都对。哪种合适取决于你选的形状：「先给对方最好的」天然把公道话放在开头，
「一路追问」更适合就地让步。

**唯一不许的是给它加标签。** 不要写「当然要说句公道话」再开始说——
让步的力量来自它是真的，不来自你宣布自己在让步。

## 7. 个人经历：有才用，没有就跳过

`data/personal.md` 里有和本期张力真正对得上的真实片段，就用一句。

**没有就整步跳过。绝不编造第一人称经历。** 编出来的经历因为完全贴合论点，
反而比真话更顺滑、更假——它是最难被发现的假。

用的时候把它放在论证的关节上，不要当装饰。参照样本里那位作者写「我小学被孤立、
中学成了现充，所以我表面叶山内心八幡」——这段经历本身就是他那句暴论的证据，
拿掉它论点就塌了。这才是它该在的位置。

## 8. 结尾

**结尾落在一个具体的东西上**：一个画面、一句原台词、一个没答完的问题。

参照样本的两个结尾：

> 大概就像一封由顶级自动书记人偶写出来的信：字句优美，纸张昂贵，装帧无可挑剔，
> 只是读完以后，我仍然不知道写信的人究竟想说什么。

> （于是我默默地点开了 blue box episode 24，才发觉心中的餐巾纸盒中已然空无一物）

两个都没有总结，也没有交代「今天就到这里」。

**套话片尾不要单独占一段。** 前三期都拿一整段说「行，今天就到这里，评论区见」，
二十段里白扔一段，还白扔一次画面检索。要留 CTA 就并进最后一句，一句话说完。

## 9. 先超写，再删

**第一稿写到目标字数的 1.6 倍（1400–2000 字），然后删到 870–1300。**

不要直接照着 1000 字写。直接写短的后果是每一句都得承重，于是每一句都在发力，
于是通篇都是金句——那正是现在这三期的形状。

删是唯一能自然淘汰套话的动作：**套话的信息量最低，按信息量排序删，它第一个出局。**
而且删出来的节奏是不均匀的，因为删掉的地方不均匀。

删的顺序固定，从上往下：

1. **解释句**——「这说明」「也就是说」「所以只能」，以及所有复述上一句的句子
2. **过渡词**——「注意」「你看」「说白了」，它们不携带信息
3. **重复的例子**——同一个论点的第二个、第三个例子，留最狠的那个
4. **形容词与程度词**——「非常」「极其」「特别」，删掉后句子通常更硬
5. **最后才轮到细节**

**非承重细节排在最后删，一般不删。** 它看起来最像「可以省」的东西，
因为它确实不为论点服务——但它正是全篇最不像机器的部分。删它等于把稿子删回原样。

## 10. 标分镜

按语义把稿子切成 8–20 段，每段配一条画面需求：

```markdown
## 段落 3

配音：他算准了说什么最快能让人讨厌他。

画面：
  查询: 角色承认自己是故意惹人厌的
  备选: 我从一开始就打算这么做
```

**`查询` 写什么决定了检索能不能命中**，它要匹配的是**台词语义**，不是画面构图——
索引建在字幕上，检索的是人物说了什么、在表达什么情绪。

- 有效：`角色承认自己一直在逃避` / `对被理解这件事表示怀疑`
- 无效：`中景，逆光，樱花飘落` —— 字幕里没有这些信息，必然检索不到
- 无效：`角色独自走远的背影，没有说话` —— **找「没有台词的画面」等于问字幕索引要沉默**，
  必然落空。2026-07-29 实测三条这样的查询全部塌到同一句无关台词（全场最低三名）

### 把查询写成台词，不要写成动作描述（2026-07-29 实测）

同一个画面，**用台词原话的口吻去查，比描述角色在做什么高一大截**：

| 段 | 描述式 | 台词式 | 增益 |
|---|---|---|---|
| 告白那场戏 | `角色当众向对方告白说自己一直喜欢她` 0.508 | `我从很早以前就开始喜欢你了 请和我交往吧` **0.873** | +0.365 |
| 事后一切照常 | `角色在事情结束后独自承担后果` 0.468 | `户部没有被拒绝 男生们的关系也不错 等到了明天一切如前` **0.864** | +0.396 |
| 牺牲的定义 | `角色当众说出让所有人反感的话…` 0.470 | `如果为了守护一些事物 就必须做出某些牺牲` **0.759** | +0.289 |

五组对照平均 +0.239。原因很直白：索引里存的就是台词本身，
检索模型比的是句子和句子，不是句子和剧情梗概。描述式那 0.5 左右的分数看着能用，
实际命中的往往是「情绪相近但事件不对」的另一场戏——
**告白那段原本检索不到告白，命中的是十分钟前商量要不要告白**。

所以：**配音里凡是引用或转述了原台词的，`查询` 直接写那句台词。**
写不出原话就写你希望角色说出口的意思，仍然用「说话」的口吻。

`备选` 在检索无匹配时使用。**留空是允许的**，检索器会退到降级方案。

### 可选字段：`人物`（2026-08-03 增补）

视觉索引建好之后（ADR-0003），分镜多了一个字段，**不写就是上面的现状**：

```markdown
画面：
  人物: 雪乃                          ← 台词检索照旧，但候选只留检测到她的镜头
  查询: 雪之下同学 你果然什么都做得很好啊
  备选: 我只是习惯了而已
```

> **`场景` 字段现在不能用**（2026-08-04）。它设计上走画面语义检索，
> 但那一层的探针没过——**门槛立不住**，详见 ADR-0003 待实测第 4 条。
> 现在写 `场景` 会当场报错，这是有意的终态，不是过渡态。
> **要氛围镜头就照常写 `查询`**，或者留给人在第 05 步换素材。

**什么时候写 `人物`：这一段指名道姓在讲某个角色。** 它修的是一类具体的错配——
台词检索命中的是「谁说了这句话」，而镜头就在**说话人**身上。
2026-07-30 踩过：配音原文「雪之下雪乃。」检索得分 0.750 很高，
可那个镜头拍的是说话的人，不是她。写上 `人物: 雪乃` 就能把这种候选筛掉。

名字必须在 `config/characters.json` 的名表里，写错当场报错——
**不是静默返回空**，因为「写错名字」和「他这段没出现」是两回事。

`场景` 本来是给「这一段要的是氛围而不是某个人」用的（空镜、雨、夜景、走廊、背影），
**但它当前不可用**，理由见上面那段引文。

`人物` 与 `场景` **不能同时写**，写了会当场报错。理由是一段只走一个通道：
台词分数和画面分数不是同一个量，并跑之后没有任何办法把它们放在一起排序。

## 11. 自检：两遍回读，分开做

先跑机检：

```bash
python -m pipeline.check_script data/episodes/<本期>/02-script.md
```

机检覆盖：字数、段数、时长、气口段上限、句长起伏、长句下限、短句配额、套话、
论文连接词、括号引号、阿拉伯数字、模糊指代、剧情锚点、查询构图词、查询重复。

**机检全过不代表能交。** 上一期就是机检全绿而被判定「机器味太浓」——
机器只能证伪，不能证明。剩下的分两遍自己过，**不要混着做**。

### 第一遍：保真

去味改写最容易破坏的就是事实，所以先查事实，后查味道。下面这些是**不许动的**，
凡是改写过的句子里带了它们，逐条回原片或笔记复核一次：

- [ ] 台词原文——一个字都不能改，包括语气词
- [ ] **说话人**——每一处「某某说」都抽帧确认过（见第 1 步；字幕没有说话人字段）
- [ ] 季/集号、专有名词、人名
- [ ] 数字，以及数字修饰的对象

- [ ] 张力取自 `01-topic.md` 且校验通过，没有在本步自行更换
- [ ] 没有编造的第一人称经历

### 第二遍：去味

只有第一遍全过了才做这一遍。固定只查这六条：

- [ ] **出声念了一遍全文**，没有断气的地方、没有念着别扭的句子
- [ ] **每段最后一句抄出来排成一列**，不是一串金句合集（至少 3 段不收落点）
- [ ] 没有解释句——删掉它观众看不懂的，才留
- [ ] 「不是 X，是 Y」全篇 ≤2 次，没有三连排比
- [ ] **读过上一期的稿子**，形状、开场动作、口头禅三样都换了
- [ ] 料单里的非承重细节至少 3 条进了正文

以及内容层面的四条：

- [ ] 每个论据都回答了「不这样会怎样」或「为什么不是别的原因」
- [ ] 篇幅不是三段并列平均分配，最在意的那个场景明显最长
- [ ] 公道话存在，单独看像反方在说话，且没有给自己贴「说句公道话」的标签
- [ ] 结论能想象出一条反驳的弹幕；结尾落在具体的东西上

## 边界

**政治议题不写。** 见项目 CLAUDE.md——自动生成的政论稿过审风险高，走人工通道。

**写不出来就说。** 张力立不住、剧情查不实、素材不足以支撑判断——
直接报告卡在哪一步，不要降低标准硬凑一篇。
