# 写稿

产出一篇口播稿与逐段分镜标注。口播稿是**念出来**的，不是给人读的——写完出声念一遍，
这是最终判据。

字数带：先读这一期的 `01-topic.md` 有没有 `时长目标` 字段，写了就按它换算
（分钟 × `config/project.json` 的 `script.cpm`），没写就是默认 870–1300 字。
`check_script.py` 认同一个字段，标准不会对不上。**这条默认带是短打杂谈类的账号实测数据，
不适用于天然需要更多篇幅的体裁（人物志、剧情回顾、共鸣）**——后者必须在 `01-topic.md`
写 `时长目标`。换音色要重推 cpm 这条线。

## 元规矩：先读这三条

**一、写的时候忘掉这份文件。** 它是动笔前的提醒、写完后的检查清单，**不是照着走的分步模板**。
写的时候你是那个看完这部番、憋着话想说的人——把规则忘了，想清楚了再写，别「第一步、第二步」
地凑。这份文件的存在理由是**防差**（防事实错、防念不出来、防和上期一个样），防不住好；
好是靠你自己琢磨出来的，不是靠逐条满足判据。

**二、先定题材，再定骨架。** 骨架从题材里长出来，不从模板里选。五种题材五种骨架
（见第 4 节），不许拿一种骨架套所有题材。`01-topic.md` 的「类型」字段没有就停下来先定。

**三、判据和机检必须同时改。** 数字和文字打架时数字赢（踩过：`max_sentence` 焊死在 40，
同一份文档写着「整句可以很长」）。动判据就同步动 `config/project.json`，
对照数据在 [BASELINE.md](BASELINE.md)。

leading word 贯穿全流程：**念得出来**、**张力**（题材决定它是什么）、**细节**、**不重样**。

| 同目录 | 什么时候读 |
|---|---|
| `VOICE.local.md` | **动笔前必读。** 这篇稿子的声音是这个人 |
| `VOICE.md` | 只在 `VOICE.local.md` 不存在时。空模板——这时不要假装有声音样本，提示用户去填 |
| [SHOTLIST.md](SHOTLIST.md) | 标分镜时。`查询` 会被原样送进检索，是机器接口不是备注 |
| [BASELINE.md](BASELINE.md) | 要改节奏阈值时。里面列着参照的人类文本样本 |

机器上还装了通用写作 skill `human-writing`，冲突时以本文件为准，理由见文末。

## 0. 先定这一期的题材

读 `01-topic.md` 的「类型」字段。没有就停下来报告，退回选题。

五种（**不是穷尽**——新的题材先在 01-topic.md 里定义它是什么、骨架长什么样、拿什么当范本，再动笔）：

| 题材 | 一句话本质 | 张力在哪 | 结尾 |
|---|---|---|---|
| 人物志 | 一个人的一生 | 他真实的经历与人性，不编论点 | 平实收尾，可预告下期 |
| 剧情回顾 | 把一条线讲清楚 | 故事本身的转折与代价 | 回环落点，或一句判断，或悬念 |
| 杂谈 | 对一部作品发表观点 | 驳论=通行说法vs事实；立论=被低估/说不通的地方；吐槽=无 | 驳论落具体东西；立论一个判断不装权威；吐槽一句自嘲 |
| 盘点 | 按一条标准过几个对象 | 标准本身 | 回环，或升华，或退场 |
| 共鸣 | 把戳人的故事讲出来 | 角色真实经历里让人心疼的东西 | 回收意象，或台词收束，或行为细节 |

按题材跳到第 4 节对应小节，把骨架和范本看一遍，然后回来走第 1–3 步。

## 1. 先把剧情查准（所有题材通用）

要用到的剧情事实——哪一季哪一集、什么场合、谁做了什么——**开写之前先确认**。
**开写前先逐段读 `data/library/notes/<番>.md`（写厚版笔记，含分集剧情 + 来源行），
这是剧情事实的唯一主源**，写稿照它写，不凭记忆、不靠 prompt 里带的那点剧情梗概。
读不到笔记就停下报告，不许裸写。

笔记里每一条剧情断言都带**来源行**（字幕索引命中 / 哪一集哪一秒 / URL）。写稿时对要落进
正文的断言核对它的来源：来源是字幕/画面的回 `.ass` 或抽帧确认；来源是网上的回原帖。
**笔记里标「未经证实」的断言不许当承重材料用**——要么换一条有来源的，要么标「待 02.5 确认」。

「某某说」之前必须抽帧确认说话人——这是记忆最不可靠、而工具最帮不上忙的地方：
字幕索引的 `Name` 字段字幕组基本不填，检索出来的时间点对，说话人只能靠记忆。

```bash
# 1. 检索定位这句台词在哪一集第几秒
python -m pipeline.subindex search "别再那样自我牺牲了" -k 3

# 2. 抽那一秒的帧，看画面上谁在说话
ffmpeg -ss <秒> -i <该集 mkv> -frames:v 1 -vf scale=480:-1 /tmp/who.jpg
```

画面和稿子不一致时，先怀疑稿子。

## 2. 捡料：先攒过量的具体东西

**开写之前列一张料单，至少 20 条，最后大概只用得上 8 条。** 料分三类，各占约三分之一：

- **原台词逐字**。不是转述，是那个人当时说出口的那句话，一个字不改
- **画面上能看见的东西**。抽帧看，把看见的具体物件、动作、表情记下来
- **观众自己生活里的场景**。不是「一个人吃饭很孤独」，是「食堂里把托盘端到最靠墙那张桌子」

**至少 3 条必须是「非承重」的**——拿掉它你的论点一点不受影响。这是「像人写的」和「像机器
写的」之间最大那道分界：机器写的每一句都在服务论点，而正是那些不为论点服务的细节
让人相信这个人真的存在过。所以料要**过量地捡**，捡的时候不要问「这条有什么用」。

**开写的硬线：承重料 ≥5 条且写得出出处（哪一集、什么场合、哪次抽帧看见的），非承重料 ≥3 条。
凑不够就停下来报告**，退回查证或退回选题。字数是目标，料是底线；料单写在 `02-script.md`
头部元信息区，不占字数。

## 3. 动笔前先找到说话的位置

在内部回答这五件事（答案不写进稿子，写的时候带着）：

1. **谁在说这件事。** 他凭什么知道——看过几遍？哪一幕印象最深？哪些地方只是在猜。
2. **什么事让他现在想说。** 是刚看完的某一集、评论区的一条弹幕、还是憋了很久的一个疑问。
3. **手里有什么能托住这篇的东西。** 优先找动作、原话、时间点、画面上的细节。
4. **他对哪一点有明确判断，依据是什么，到哪为止。** 哪一块至今没想通，就直接说出来。
5. **听众听到上一段以后，最自然会追问什么。** 下一段回答它。

这一步是「说人话」的根：人的话是从一个具体的处境里长出来的，不是先有主题再填话。

## 4. 各题材骨架

> 每个骨架都是从**真实存在的优秀文本**里拆出来的，范本列在各节里，可以照着拆原文看它是
> 怎么走的。骨架是「这类内容通常怎么走通」，不是必须照抄的分步模板——写的时候按你自己的
> 想法来，只在形状和题材严重不匹配时，回来对照一下是不是绕远了。

### 4.1 人物志

**范本：当期 `reference.md` 里的真实文案（罗十五，两期董香）。** 这套写法就是照它拆的。

一个人的一生。讲经历，不证明论点。

- 从故事里这个人给观众的第一印象入手，或从时间线的起点入手。
- **按经历发生的顺序讲，讲完一段，贴着一幕评一段。** 点评是此刻看到这一幕的反应，
  不服务全篇一个统一判断。可以是这样：「这里我第一次觉得她好看」「他这个动作我看不懂」
  「我个人觉得有两种可能」——人的评价是边走边说的，不是最后总结的。
- 人物的挣扎写实。把她失去的、独自扛着的、咽回去的写出来。**能自己站住的事实不需要人扶**——
  写一个人脑梗死，写「起床、发愣、躺下、五分钟、六十七岁」，别写「他的生命戛然而止」。
- 段落不追求每段都收口。很多段落只是把一件事讲完，甚至岔开一句——正是这些不收口的段，
  让下一段的落点砸得响。
- **没有模式、没有张力字段。** 不为了「有观点」给角色安一个论点再回头挑经历——刻意找张力，
  本质是哗众取宠、没有同理心。张力来自他真实的经历与人性：失去过什么、扛着过什么、
  在哪一步选了更难的路。找不到就不硬找，平铺直叙把一个人讲清楚，也是好看的。
- 结尾平实收尾，连载可以直接预告下期（「这一期先讲到这里，下一期接着讲」）。

### 4.2 剧情回顾

**范本：bangumi 剧情梳理长评——《命运石之门0》第 8 集跳线原因（blog/352834，纯因果回溯）、
《记忆管理局》分集回顾（blog/378265，重述与点评分离）、《来自新世界》日记节选（blog/361133，
长文里的压缩式回顾）。** 口播侧参照阿斗归来了（反问+离奇事件开头、人物动机驱动、结尾原创解析）。

把一条故事线讲清楚。对象是一个事件、一段关系、一季或一条线索，不是整部作品——
全集一口气讲不完，8–20 段撑不住。

- **开场 = 给钥匙 + 给钩子**（二选一或都用）。给钥匙：先讲清理解全文必需的 1–2 个前提
  （世界观规则、一句话主题），让观众手里有地图再进剧情（「首先我们明确一个事实」）。
  给钩子：用一个未解之谜开场，逼观众想知道谜底
  （「第 8 集的跳线原因，一直埋到第 22 集才填坑」）。不许「今天给大家介绍一部作品叫 XX」的报幕开场。
- **推进 = 一条主线 + 因果咬合**。只跟一条主线（一个物件、一个谜团、一个目标），跑题的细节砍掉。
  事件之间用因果接，不用「然后然后」：A 发生 → 导致 B → B 让 C 成为可能 → 结果 D。
  复杂设定就地插入解释，一段内解决，不另起炉灶打断主线。每讲完一个阶段给一句「当前状态」，
  让听众有进度感。
- **人物动机驱动**：讲清楚每个人为什么这么做——观众记住的是「人」，不是事件堆
  （阿斗自述「以故事推动角色，而不是角色无情地推动故事」）。
- **重述与点评分开**。重述归重述，点评另起一段。混在一起会又碎又乱。
- 台词用来承接因果，转折点往往是那句关键台词。
- 这一题材天然要更多篇幅，记得在 `01-topic.md` 写 `时长目标`。
- **结尾 = 回环落点**：回到开场的前提/谜题，回答「为什么这一切最后成立」；
  或者落在一句自己的判断/解析上；没完结的就收拢成悬念，不强行结案。

### 4.3 杂谈

**范本：bangumi 长评——「论反本质的真物」（blog/311213）、「Oregaku 关于春物的杂谈」
（blog/361121）、「洞穴中的人及试图拉他们出洞的人」（blog/315100）。** 这类是深度解读/观后杂谈的实样。

对一部作品发表观点。先定子型（`01-topic.md` 的 `模式` 字段）。

**立论·深度解读**——作品里有个被低估的、说不通的地方，把它讲通。这是杂谈的基本功，
优秀长评的共同骨架：
- **开头先立说话位置**：为什么现在想说（刚补完、后劲大）、看了几遍、偏好哪一边。
- **把说不清的东西打比方说清。** 真物长评讲「真物无法言说」，打的是漩涡/黑洞的比方——
  抽象的东西落成一个能看见的画面，观众才接得住。
- **分维度、分人物推进。** 每段一个维度（距离、理由、理想），或一个人物（八幡、雪乃、结衣），
  每段的证据全部落在**具体剧情事件和原台词**上，不空谈。
- **诚实。** 明确标出「这是推测」「这块我没看懂」「碍于篇幅不展开」，也指出作品真实的缺点
  （制作硬伤、改编问题）——这不是自谦，是可信度的来源。拿不准的地方全篇一处。
- 结尾给一个**自己的判断，但不装权威**——可以承认「我也没完全懂」。

**驳论**——大家都信的说法经不起推敲。
- **先给对方最好的**：开场把通行说法讲到观众开始点头，然后在某个具体处掀掉它，剩下全程守这一刀。
- 靶子（通行说法）必须是你真听过的：弹幕、评论区、别的视频、你自己以前的想法，
  至少能想起一处。想不起来就是稻草人，停下退回选题。
- 靶子打在**论证过程**上，不一定打结论——想保留基本盘时尤其如此
  （「团子确实不该赢，但『输在温柔不敢争』站不住」）。
- 论据每个都得回答「不这样会怎样」或「为什么不是别的原因」，落在可指认的剧情事实上。
  给例子不算论证——任何论点都能在几十集里找到一句配得上的台词。
- **公道话**：在自己的立场内部，主动给对自己不利的具体反例，然后守住判断。
  判据：这段话单独拎出来，像反方在说话。「凡事都有两面性」这种空转不算。不贴「说句公道话」的标签。
- 篇幅按在意程度分配，不平均——最在意的那一场挖到底，其余点到为止。
- 结尾落在一个具体的东西上：一句原台词、一个画面、一个没答完的问题。

**吐槽**——图一乐。**不吃张力、公道话那套判据。**
- 从最想喷或最好笑的点开始，一个点一个点地来，点到为止，不较真。
- 收在一个梗或一句自嘲上，不升华。

三种子型共通的：段落之间是推进不是并排，上一段留下的问题，下一段回答它。

### 4.4 盘点

**范本：知乎专栏「眯眯眼都是怪物」盘点（zhihu.com/p/357839891，条目三件套与压轴回环）、
bangumi「构成我的九部动画」（blog/369922，每条一个具体到荒谬的细节）、bangumi「2024 四月
新番观感报告」（blog/344226，每部一个判词+密度不均）。** 口播侧参照凉风「阅片无数」
（招牌开场、标题即钩子、个人偏好+致敬收尾）。

按一条标准把几个对象过一遍，标准本身是论点。

- **开场三步**：① 钩子——一个人人熟悉的现象/情绪，让观众点头
  （「眯眯眼是动漫里最常见的几种人设之一」）；② 落差——现象 ≠ 直觉认知
  （「不知从何时起，眯眯眼和战斗力挂上了钩」）；③ 立标准 + 设防——说清入选准则，
  主动承认这是个人口味（「排名无关先后」「我是原创动画爱好者」）——主动坦白偏见是防杠的根本手段。
- **每个对象三件套**（防报菜名的核心）：定性句（一个词/一句判词）+ 证据
  （名场面、具体到荒谬的细节）+ 金句（反差或梗，让观众停一下）。对象之间互相对照垫背。
- **压轴位要设计**：越往后越重（梗越极致或情感越浓），最后一名不是「最该上榜的」，
  而是「最有记忆点的」。
- 论证放观众生活里（约八成），台词只当钩子（约两成）。判据：每段的落点是「你」，不是主角。
- 篇幅按在意程度分配，不平均。
- **结尾三选一**：回环（最后一句复刻标题/标准，回到开场那个现象）、升华（从作品跳到人生/时代）、
  退场（「还有别的，点到为止」，用情绪收尾不硬总结）。

### 4.5 共鸣

**范本：bangumi「你的真心究竟在何处？」（blog/327001，物件贯穿+回收意象结尾）、
「致凋亡季节中的你」CLANNAD（blog/375742，台词收束不总结）、知乎「哆啦A梦·大雄奶奶」
回答（zhihu.com/question/635431889，防御→失守+行为细节）。** 口播侧参照凉风「这是一个关于
火影的故事」、抖音「意难平/破防」流。

把一个戳人的故事或一段关系讲出来，目的是打动，不是分析。

- **开场三招**：① 动机自白——「想写很久了」「这部作品对我是私人的」，先宣告我在讲心事，
  把观众从「品评」切到「倾听」；② 不可伪造的细节——精确时间、具体动作
  （「爬树，挖坑，互相扔砂土」），具体性本身就是真诚的信号；③ 防御→失守——
  先承认「前面我只是在看个动画」，再让引爆点出现。
- **推进 = 个人经历与作品情节交替抵押**。讲一段剧情，插一段「我也遇到过」，
  再用「其结果是一样的」焊死——作品成为解释我人生的工具，我也成为理解作品的入场券。
  一个贯穿全文的象征物（花瓶、塑料花、时光机），让抽象情感有可触摸的实体。
- **追问代替陈述**。「你为何而哭？」结论交给观众自己得出，比直接煽情高级。
- **不归纳道理、不点题。** 「他其实很孤独」这类话不要说，把他的孤独写出来就够了。
  情感不靠形容词堆，靠事实的排布，最能戳的那一幕放最后。
- **结尾三选一**：回收开头意象（开头埋的物件一件件拿出来还）、引用作品台词/歌词收束不总结
  （让作品最后说一次话）、行为细节代替情绪直说（「看到这一集基本都是跳过」）——
  最轻的一句话收最重的情。

---

## 5. 语言：念得出来

**写完出声念一遍，这是最终判据。** 念着别扭的句子就是有问题，别留着。

- **短句是标点，不是常态。** 全篇十句短句，一句都不响。长句要靠逗号撑开，不是一个念头里塞修饰。
- **不要解释你刚说的话。** 一句话说完就完了，下一句不要告诉观众刚才那句意味着什么。
  判据：把这一句删掉，观众会不会看不懂？不会，就删。
- **「不是 X，是 Y」少用，用了就删前半句。** 三连以上的排比整段重写。
- **同一种修辞全篇不超过两次。** 反问、复述对方的话再打、破折号转折，各上七八次就成了口癖。
- **大白话，不掉书袋。** 判据：这句话能不能对着一个没读过这专业的人当面说出口。
- **「我」高频，「你」直接称呼，该有的语气词（啊/吧/嘛/哇）不要修掉。**
  但说话的痕迹**每期现造**，不要从清单里挑——上一期用过的开场动作、口头禅，这一期一个都别用。
- **套话不要加禁令，去看它为什么出现。** 一句话如果需要前面那句来宣告它的分量，问题在那句话本身。
- **哪一块没想通，直接说出来，全篇一处。** 不放在结论上——每个论点后面都挂一句「当然这也
  说不准」是打太极，挂到结论上，结论就没了。
- **听众不能往回翻。** 代词找得到人（出现「他」时，上一个说出口的人名必须就是这个「他」）；
  专名第一次说全，之后固定用一种叫法；一段里数字只留听众必须记住的那一个。

## 6. 先超写，再删

**第一稿写到目标字数上限的 1.6 倍，然后删回目标带。**

不要直接照目标字数写——直接写短的后果是每一句都得承重、每一句都在发力，通篇都是金句。
删是唯一能自然淘汰套话的动作。删的顺序固定：

1. 解释句——「这说明」「也就是说」「所以只能」，以及所有复述上一句的句子
2. 过渡词——「注意」「你看」「说白了」
3. 重复的例子——同一个论点的第二、第三个例子，留最狠的那个
4. 形容词与程度词——「非常」「极其」「特别」
5. 最后才轮到细节

**非承重细节排最后删，一般不删。** 它不为论点服务，却正是全篇最不像机器的部分。

## 7. 不重样

**开写之前把 `data/episodes/` 里上一期的 `02-script.md` 读一遍。** 记住三件事，本期都要换：

- 上一期的骨架与开场动作（摆靶子？抛疑点？给钥匙？先讲一个画面？）——换一个
- 上一期的段落推进方式——换一种
- 上一期反复出现的口头禅——一个都不许再用

模型没有跨会话记忆，不主动去读就必然收敛到同一个默认形状——**雷同不是巧合，是没人回头看过。**

## 8. 标分镜

按语义把稿子切成 8–20 段，每段配一条画面需求。**动手前读 SHOTLIST.md。**
不读也别踩的一条：`查询` 匹配的是**台词语义**，不是画面构图——索引建在字幕上，
写 `中景，逆光，樱花飘落` 必然检索不到。

```markdown
## 段落 3

配音：他算准了说什么最快能让人讨厌他。

画面：
  查询: 角色承认自己是故意惹人厌的
  备选: 我从一开始就打算这么做
```

## 9. 自检：两遍回读，分开做

先跑机检（它覆盖哪些项跑一下就全打印出来了）：

```bash
python -m pipeline.check_script data/episodes/<本期>/02-script.md
```

**机检全过不代表能交。** 分两遍自己过，不要混着做。

### 第一遍：保真

去味改写最容易破坏的就是事实，所以先查事实，后查味道。这些是**不许动的**，
凡改写过的句子里带了它们，逐条回原片或笔记复核：

- [ ] 台词原文——一个字都不能改，包括语气词
- [ ] 说话人——每一处「某某说」都抽帧确认过
- [ ] 季/集号、专有名词、人名
- [ ] 数字，以及数字修饰的对象
- [ ] **剧情断言逐条核对笔记的来源行**——正文里每处「谁在哪做了什么」能在笔记里追到来源
  （字幕命中/抽帧/URL），笔记里标「未经证实」的一句都没进正文当承重材料
- [ ] 没有编造的第一人称经历（`data/personal.md` 里没有就整步跳过）

### 第二遍：去味

只有第一遍全过了才做这一遍：

- [ ] 出声念了一遍全文，没有断气、没有念着别扭的句子
- [ ] 每段最后一句抄出来排成一列，不是一串金句合集
- [ ] 相邻两段说得出推进关系，不是并排的另一个论点
- [ ] 没有解释句——删掉它观众看不懂的，才留
- [ ] 读过上一期的稿子，骨架/开场/推进/口头禅都换了
- [ ] 料单里的非承重细节至少 3 条进了正文

以及内容层面的（按题材取）：

- [ ] 人物志：按经历顺序讲；点评贴着当下的一幕；没有给角色安论点
- [ ] 剧情回顾：一条主线+因果咬合，不是时间线流水账；人物动机讲清了；
  结尾回环/一句判断/悬念
- [ ] 杂谈·立论：开头立了说话位置；每段有具体剧情+原台词当证据；标了推测和作品真缺点
- [ ] 杂谈·驳论：每个论据都回答了「不这样会怎样」或「为什么不是别的原因」；
  靶子是真听过的说法；公道话存在且单独看像反方在说话
- [ ] 盘点：开场三步（钩子/落差/立标准）；每个对象是定性句+证据+金句；压轴位设计了；
  落点是「你」
- [ ] 共鸣：没有归纳道理；有贯穿的细节/物件；结尾是回收意象或台词收束或行为细节
- [ ] 结尾落对了地方（各题材见第 4 节）

## 和 human-writing 的关系

`human-writing` 是通用中文写作 skill，面向知乎和公众号长文，不面向口播稿。冲突处**以本文件为准**：

- 它禁破折号、冒号——这里不禁。破折号是 `VOICE.local.md` 记着的本人特征；
  冒号是 `配音：` `查询：` 机器接口，`check_script.py` 靠它解析
- 它禁「不是X而是Y」——这里只限 ≤2 次

值得借的已经并进本文件（第 3 步说话位置、第一稿直接带着人写、写的时候忘掉规则）。
别拿它的 `check_prose.py` 检 `02-script.md`——稿件机检只有 `python -m pipeline.check_script`。

## 边界

**政治议题不写。** 见项目 CLAUDE.md，自动生成的政论稿过审风险高，走人工通道。

**写不出来就说。** 题材没定、剧情查不实、素材不足以支撑——直接报告卡在哪一步，
不要降低标准硬凑一篇。
